Use compensation carefully

  • Set a stable material flow profile first; extrusion consistency and whole-part scale are separate checks.
  • Calculate hole and pin clearance separately; whole-model scaling does not solve every fit problem.
  • Check the exported STL dimensions before slicing.
  • Read the shrinkage compensation guide.
