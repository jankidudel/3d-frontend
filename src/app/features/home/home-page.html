3D Quality Tools

Free tools to check, measure and prepare 3D printing files.

What a collection review gives you

Owned software example, not a physical print test. Each file keeps its own outcome:

  • Closed 20 mm cube: 12 triangles, zero boundary edges, 8,000 mm³ screened volume. Confirm skipped printer fit before slicing.
  • Open-face cube: four boundary edges and unavailable volume. Inspect the intended missing face before repair.
  • Malformed STL: failed processing. Re-export; failure cannot count as zero errors.

The report records units, settings, method limits and the next action, with CSV, JSON and printing. Optional history stays in this browser without original geometry.
