Example model: a missing face changes the next step

A closed 20 mm cube has 12 triangles, zero boundary edges and 8,000 mm³ screened volume. Removing one square face leaves four boundary edges and unavailable volume. Unavailable does not mean zero.

Inspect the opening first: if it is intentional, automatic filling changes the design. If it is missing geometry, correct it and recheck the exported file.

From file to slicer review

  1. Inspect: confirm size, units and the intended objects.
  2. Interpret: decide whether a finding is a fault or part of the design.
  3. Correct: preserve the original and make the smallest justified change.
  4. Compare: recheck dimensions and geometry after exporting.
  5. Slice: review supports, excluded bed regions, material settings and the machine profile.

Geometry checks do not determine strength, machine safety or all support requirements.

Where your files are processed

Viewers, scale adjustment, collection review and several planning tools run in your browser. Some quality, topology and volume checks upload the selected file for server processing. Each tool explains its own processing before you choose a file.
