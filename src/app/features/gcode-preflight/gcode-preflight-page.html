G-code preflight FAQ

Can this prove a file is safe to print?

No. Firmware, machine configuration, material, calibration, start G-code and slicer profile affect the print.

Why can the parsed preview be incomplete?

Arcs, macros, conditional logic, multiple tools and vendor-specific commands can limit a browser parser.
