Choose the result you need

For a hardware interface, choose the screw-hole role, head seat or nut-pocket requirements first. The fit worksheet performs circular arithmetic, a viewer records selected geometry and uniform scale changes every length; none selects the hardware for you.

Start with a viewer for display, preflight for a broad diagnostic, or a specialist check for one finding. STL checks require an assumed unit; 3MF checks resolve declared units and build instances. A repair tool changes geometry, while a checker explains it. Use the guide linked from a tool when the next action is uncertain.

Sample uploaded geometry first, then use the dimensional planner for approximate line arithmetic and the flow planner for requested throughput. Review actual sliced paths and complete consumption after changing walls or infill or the layer schedule; a geometry volume does not infer those settings.

Cost estimates describe production inputs. Price planning adds quantity and margin to prepare a quote. Start with complete slicer values when estimating filament or time.

Inspect sliced instructions, calculate requested throughput, then add a reviewed duration to a chosen start. Requested speed alone supplies neither a tested flow limit nor elapsed job time.

If a file opens but detail disappears after slicing, start with the stroke, gap and relief checks or missing-roof triage. A material-wall screen and a slicer's generated paths answer different questions; choose a correction after locating the changed feature. For an existing face, distinguish seam placement from top-fill or an additional surface pass; numeric orientation fit does not select either. Review the actual native slice, then carry complete new totals into costing and agreed finish into the quotation.
