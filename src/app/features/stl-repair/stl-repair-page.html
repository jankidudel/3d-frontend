How disconnected-piece review works and its limits

Review loose parts in three steps

  1. Choose one STL above. Automatic detection retains every piece.
  2. The example opens review automatically. Use Previous and Next to inspect pieces, or press Keep largest part to propose the greatest-area component. Similar areas trigger a warning and require confirmation. Restore intended pieces with Keep, or reset to keep all.
  3. Download STL with kept pieces to save the retained triangles, then inspect the separate copy in your slicer.

Download the binary demonstration STL or the ASCII version. These are generated files for testing through the picker above.

Counterexample: separate pieces can be intentional

Two intended cube parts has 20-unit and 19-unit cubes: 2 parts / 24 triangles. Both start retained. Their areas differ by less than 10%, so Keep largest part first warns and asks for confirmation. Reset restores both. Removing the smaller one by size alone would discard an intended object. Lettering, inner cavity surfaces and print-in-place mechanisms can also contain necessary disconnected shells.

How are separate shells found?

A component is a group of triangles connected through complete shared edges. Exact coordinate matches are used, even for STL triangle soups; there is no tolerance welding. Point contacts, small gaps and intersecting surfaces with no shared edges may remain separate. Component counts do not establish defects or artistic intent. Open and non-manifold components have area and bounds, but no inferred reliable volume. Zero-area faces require an explicit standard repair first.

Can size identify unwanted pieces?

No. The review order uses surface area, with triangle count and stable part ID as tie-breakers. Smaller islands or loose parts may be important. Inspect each piece in context before changing its Keep selection.

Do dimensions change?

Retained vertices keep their coordinates, winding, scale and position. Overall file bounds can shrink when you remove an outer piece; the retained body is not resized or moved. STL is unitless; displayed millimetres are assumed. ASCII coordinates are retained in ASCII output; binary input keeps its stored Float32 coordinates. Normals are recalculated, and colour/material metadata is not preserved.

What about floating regions in a slicer's layer preview?

A slicer floating region can belong to one continuous model. This tool does not detect every unsupported region or generate supports. Removing disconnected pieces does not guarantee printability, manifoldness or watertightness. Use the disconnected-shell guide and STL Print Preflight to interpret remaining issues.

Component analysis is limited to the existing 25 MiB file allowance and 500,000 triangles. Heavy parsing, connectivity and verified export run in a cancellable browser worker. The list shows 30 parts per page, and the full-resolution preview batches retained and removed triangles into two meshes. No unlimited-file promise is made.

Cleanup removes redundant faces, not missing design

The supported actions remove exact duplicate triangles and degenerate triangles (faces with no useful area), then attempt orientation correction in closed manifold regions. Retained vertex coordinates are not smoothed or resized. Removing a redundant face is different from reconstructing a missing surface: holes, intersecting bodies and ambiguous internal geometry need a design decision in CAD.

Try a narrow, reproducible repair

Download the 20 mm cube with one duplicate triangle. It contains 13 triangles: the 12 faces of a consistently oriented cube and one repeated triangle. Select it above, then explicitly submit cleanup. Check that the report removes one duplicate, preserves 20 × 20 × 20 coordinate spans and produces a separate copy. Reopen that copy, inspect the six surfaces, check topology and compare it with the original. A smaller triangle count alone does not prove that intended features survived.

Before submitting and after downloading

The retained local processor run removed the duplicate and reopened its actual saved output as a valid 12-triangle cube with 20-unit spans. Download that saved cleanup control and its reopened report. This is evidence for that narrow operation, not a claim that every defective STL can be repaired or that production is running this revision.

STL cleanup uploads the selected file to InspectMesh for server processing when you press Clean STL safely. Selecting or downloading an example is not permission to upload it automatically. Keep your original and avoid submitting confidential designs unless this processing is appropriate for you.

Malformed records, invalid coordinates or upload-limit failures can prevent a job from running. A completed job can also report that no safe change is available. Read skipped reasons instead of repeatedly submitting the same file. If open boundaries remain, return to the source model or an explicit mesh-editing workflow; this tool cannot infer the missing shape.

Stop using the cleaned derivative if dimensions, intended shells or important features change unexpectedly. The output passing mesh validation still does not certify strength, fit or a physical print. Compare the revised surfaces before accepting it.
