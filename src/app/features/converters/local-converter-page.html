What this conversion keeps

STL stores geometry but no units or slicer settings. This converter creates a basic 3MF with the geometry and the unit you choose; it cannot recover print settings, materials or colours that were never in the STL.

@if (kind === 'stl-to-3mf') {

A declared unit does not recreate CAD

This local converter writes triangle geometry into a basic 3MF model with one build item and your chosen coordinate-unit declaration. If coordinates span 20 and you choose millimetres, the package describes 20 mm; choosing inches describes 508 mm. It does not multiply coordinates to fix a prior modelling mistake.

Try the 20 mm cube, select millimetres, convert and reopen the downloaded package. Check 20 mm spans and the original triangle count in 3MF Preflight. A unit declaration adds useful context but cannot restore analytic cylinders, native CAD features, source material intent, colours or slicer-project profiles. Conversion is not mesh repair. Stop if the source unit is unknown or the receiving application shows a changed size; confirm the original design first.

Export from an editable CAD source when design changes are required, rather than expecting conversion to recover it.

} @else {

Verify a geometry-only export

The converter resolves supported build geometry, applies component and build transforms, converts physical coordinates to millimetres and writes one binary STL. It exports the complete resolved build on this page; there is no single-instance selection control. Separate placements become triangles in one file rather than editable build-item records.

  1. Keep the original 3MF and note its declared unit and intended objects.
  2. Download the declared-inch transformed example and convert it locally.
  3. Open the STL with a millimetre assumption: expect 25.4 mm spans and X coordinates from 50.8 to 76.2 mm.
  4. Repeat with the two-placed-cubes example: inspect both cubes and the 60 mm total X span.
  5. Compare dimensions and placement in the destination slicer before printing.

STL drops the package's unit declaration, object names, property assignments and application-specific settings. It does not Boolean-union overlapping shells. Unsupported build data should be resolved in the producing application; stop if a required object disappears. Keep project information separately from this mesh derivative.

}
