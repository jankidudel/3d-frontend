Finding Meaning
One triangle at an edge Boundary or open edge; design intent remains unknown.

If your report says...

Finding Narrow next action
Boundary edges Inspect the opening with the hole guide before filling anything.
Over-shared edges Use the focused topology repair workflow to determine the intended face.
Multiple vertex-connected components Review the separate-shell guide before keeping or removing any piece.

Method and limits: the server compares exact stored vertex positions, excludes degenerate triangles from edge counts, and connects components through shared vertices. It does not run a complete vertex-manifold or spatial-intersection test. A malformed STL returns an error, not a clean zero. For exposed-boundary interpretation alone, use the STL Watertight Checker.
