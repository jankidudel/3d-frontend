Which detail is changing?

This planner compares dimensions and equal-width line arithmetic. To find why a particular stroke, opening or roof is missing, inspect that feature in the actual sliced preview.

Detail Check in the source and slicer
XY material width Compare source width with actual line widths and perimeter generation using the wall interpretation guide.
Z relief Compare raised height or recess depth with actual first-layer, adaptive-layer and slice-plane settings. Use the lettering checks; nominal height divided by layer height is not an exact generated-layer count.
Negative-space counter Inspect whether the intended void remains open in the slice. Filled-opening diagnosis addresses this separately from material-wall thickness.
Roof Review visibility, source closure, effective top layers and mode in the roof diagnosis. Equal-width line arithmetic does not predict top closure.

Interpret wall thickness for the feature's use. If you already have a mesh, screen its sampled geometry with the STL checker or 3MF checker.

The retained T3 plaque has 0.10 mm relief. Its 0.20 mm layer/first-layer schedule has no paths above the base, while the 0.10 mm schedule records glyph paths at Z=2.1. Actual layer observations differ from nominal line arithmetic; no minimum font size is calculated here.

Actual thin-wall slicer control

PrusaSlicer 2.9.6 was run on three owned bars (0.3, 0.45 and 0.9 mm wide) with 0.4 mm nozzle, 0.2 mm layers, 0.45 mm line width, two perimeters and no infill. Classic reported 83.41 mm filament and 3m 32s; Arachne reported 142.10 mm and 5m 28s. The perimeter engine changes what gets traced. These are software estimates, not physical prints or recommended printer settings.

Inspect the actual toolpaths using the Classic and Arachne preview files. Do not print the CLI demonstration exports.

Actual nozzle control

The same owned 20 mm cube sliced at 0.2 mm layers, explicit 0.45 mm line width and 45 mm/s perimeter speed gave estimates of 23m 49s for a 0.4 mm nozzle and 23m 45s for a 0.6 mm nozzle in PrusaSlicer 2.9.6.
