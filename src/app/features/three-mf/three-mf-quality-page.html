What a 3MF quality check looks for

The checker examines resolved mesh triangles for invalid coordinates, degenerate faces, duplicate faces, open edges, non-manifold edges and inconsistent orientation.

Why 3MF units are more reliable than STL units

3MF can declare its coordinate unit, so reported dimensions retain useful scale information.

How build items and multiple parts affect a 3MF file

A 3MF can place multiple objects in one build. Separate parts are not automatically invalid.

FAQ

What is a 3MF file?

A 3MF is a package format for 3D printing models and build information.

Is 3MF better than STL for 3D printing?

It can preserve more print-model information, including units.

Does a valid 3MF guarantee a successful print?

No. Printer, slicer, material and support settings still matter.

Are my units stored in a 3MF file?

3MF can declare a model unit, which this checker reports.

Can InspectMesh repair a 3MF file?

No. This checker reports mesh health but does not modify files.
