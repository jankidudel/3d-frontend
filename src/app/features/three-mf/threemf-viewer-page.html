Measure a named feature and retain its basis

Select the intended placed item. Measurements use resolved build space; keep them distinct from resource-local dimensions and retain the placed-item identity. Point selections do not recognise hardware or validate assembly. Choose the task: screw passage, head seat or nut pocket.

Choose Distance, Angle or Circle through 3 points in Feature measurements. Surface point remains the initial selection method. Mesh vertex offers a bounded candidate from the visible hit triangle; it does not infer a CAD corner or hole centre. Angle uses side A, vertex B, side C. Circle reports a constructed radius and diameter, not roundness or clear passage. Save up to 20 named measurements in this tab and download the local JSON record before replacing the file.

Follow the angle coupon or faceted-bore and ellipse examples. Camera movement changes the view, not the stored references. Entered coordinates are available as a keyboard alternative and are distinguished from verified mesh picks.

Coordinates use the resolved millimetre build frame; the declared source unit is recorded separately. The centimetre placement example has origins at (10,20,30) and (50,20,30) mm. Review placement IDs when measuring across items: that distance describes the build arrangement, not one reused resource's local feature. Isolation never reassigns a saved point to another item. Review the displayed all-build or selected-item scope; repeated placements and object counts do not identify a moving assembly. Use the print-in-place inspection workflow to identify intended bodies and directional gaps. Resolved geometry does not turn package settings into sliced paths or establish movement.

How to use the 3MF Viewer

  1. Choose or drop a 3MF file.
  2. Rotate with drag, zoom with the wheel or pinch, and pan with right drag or two fingers.
  3. Review the displayed build geometry summary and declared unit.
  4. Choose Distance, activate Start measuring and select two visible mesh points to inspect a specific feature.
  5. Use Inspect cross-section to move a cut through the resolved build and inspect geometry that is hidden inside or behind another part.

What the 3MF Viewer shows

The viewer displays the resolved build geometry, including repeated build items and their transforms. It calculates the displayed bounds and triangle count locally. Stored resources can be reused or remain unplaced, so a resource count is not a visible-part count. Interpret stored versus placed triangle counts before assuming geometry was lost.

Overall dimensions describe the resolved build bounds. Point-to-point measurement checks a specific feature. See how to measure a 3D model for guidance and limitations.

Inspect a cross-section

Choose Inspect cross-section below the viewer, select an X, Y or Z cut axis, then move the cut through the displayed build. The viewer hides one side of the mesh for visual inspection; it does not repair, cap or validate the model. Read how to inspect STL and 3MF cross-sections for the recommended workflow.

Why 3MF differs from STL

3MF can store a declared unit and several model objects placed as build items. STL stores only basic geometry and does not declare units.

Check the intended receiving geometry

Record the source revision, required top-level placements, declared unit and a named resolved dimension or coordinate interval. For the two-cube control, build-2 is X=40..60 mm while the all-build X interval is 0..60 mm. Selection and isolation help inspect those references; they do not choose converter export scope.

This supported geometry preview does not audit all appearance data, material assignments or project profiles. A default display colour does not establish that source colour data was lost. Review required properties in the authoring/receiving application. Read the opening sequence, trace a missing placement, or record property preservation.

FAQ

Does my 3MF file get uploaded?

Viewing stays local. Optional issue-location analysis uploads the selected file only when you request it; separate server checkers have their own explicit submission notices.

Can a 3MF contain multiple parts?

Yes. The viewer displays the loaded build geometry.

Does viewing validate the model?

No. Check 3MF quality for a mesh-quality review.

How accurate is point-to-point measurement?

It measures the displayed mesh triangles. Accuracy depends on the source mesh resolution and selected points; use CAD or calibrated physical measurement for tighter tolerances.

Does this work for all 3MF files?

It resolves supported core mesh resources, components, build placements and declared units within bounded processing limits. Required unsupported extensions, cross-part references and invalid geometry stop with an explicit diagnostic. Optional project properties remain outside the geometry workflow.
