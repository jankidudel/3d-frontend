3MF Watertight Checker

Find out whether the objects placed in your 3MF build are closed or have holes. This checker counts open edges in each placed object, so you can see which one needs attention before slicing. For an STL, use the STL watertight checker; for every 3MF mesh problem at once, use the 3MF Quality Checker. No open edges means no holes were found, not that the print is guaranteed.

Read the boundary result

Result Interpretation Next action
One or more open edges At least one edge has no neighbouring face, so there is a hole or gap. Check whether that surface was meant to be closed.
No open edges No holes were found. Check the other results and your parts too; closed does not mean error-free.
File failed or not supported The check did not finish, so there is no result. Export the file again from the program that made it.

The server checks each placed object on its own, after applying the file's unit and each object's position and scale, then adds up the results. Edges are matched by exact corner positions; nearby points are not merged. Zero-area and invalid triangles are skipped, but duplicate triangles are counted. Pieces sharing a corner count as connected. It does not look for overlapping surfaces.

Placing the same object twice is fine; the same triangle stored twice inside one object is a problem. A file can hold several closed parts, and having no open edges does not mean their positions or overlaps are right. A blank volume has other causes and does not mean the file has holes.

Example: the same hole, placed twice

A cube missing one side has four open edges. Place two copies of it in a build and the check reports eight, because each copy is checked separately; fixing the hole once fixes both. This is simple arithmetic, not a test result.

Use which part of my 3MF has holes to find the affected part and the 3MF manifold checker for non-manifold warnings.
