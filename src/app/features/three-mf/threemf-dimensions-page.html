How to measure a 3MF file

  1. Choose or drop a .3mf file.
  2. Read the width, depth and height of the build as placed.
  3. Check the unit the file declares and compare the size with what you expect.
  4. Enter your printer's usable build volume to check whether the model fits before slicing.

Understanding the result

The file's unit tells you how to read its numbers. The size shown is for the whole build as placed, so a wide build may simply hold several small parts side by side; it does not mean any part grew. The main result uses the file's own unit, and the conversion panel shows the same size in millimetres, centimetres and inches.

To resize the project, use how to scale a 3MF. Changing the display unit here does not resize or save the file. Before exporting an STL, note a size and position you know, then choose what to export in the converter. The printer-fit check compares sizes only; it does not guarantee a print.

Example: the same cube placed twice

A 20 mm cube at X 0 is 20 mm wide. Place a second copy 40 mm along and the whole build is 60 mm wide, including the 20 mm gap, but each cube is still 20 mm. (Simple arithmetic, not a saved test result.)

FAQ

Does my 3MF file get uploaded?

Yes. Pressing Measure 3MF dimensions uploads the file to our server. For local viewing without upload, use the 3MF Viewer.

Do the dimensions include each object's position and scale?

Yes. They are measured after applying each object's position, scale and rotation, including nested sub-parts.

Does a fitting result guarantee that I can print the file?

No. It is a size comparison only. Your slicer, chosen orientation, supports, printer margins and print settings still matter.
