How to measure a 3MF file

  1. Choose or drop a .3mf file.
  2. Inspect the width, height and depth of the resolved build geometry.
  3. Confirm the declared 3MF unit and compare converted measurements with your intended size.
  4. Enter your printer's usable build volume to check whether the model fits before slicing.

Read the declared unit and the measured scope

A unit declaration explains the coordinate convention. The measured bounds describe the supported resolved build, including its placements. A wider build can contain several unchanged small parts; it does not mean each part grew to the overall width. The primary server result is displayed in its declared/effective source unit; the conversion panel shows the corresponding millimetres, centimetres and inches.

To resize the project, use the application workflow in the scaling guide. Changing a display unit here does not save a resized 3MF.

One resource, two placements, different bounds

A 20 mm cube placed at X = 0 spans 20 mm on that axis. Place another copy at X + 40 mm and the combined bounds span 60 mm, including the 20 mm gap. The wider build does not make either cube 60 mm wide. This is expected geometry, not a retained observation of this deployed checker.

Compare the owned one-placement package and two-placement package. Changing a display unit does not resize or re-export either package.

FAQ

Does my 3MF file get uploaded?

Yes. Pressing Measure 3MF dimensions submits the selected file for server processing. For local viewing without upload, use the 3MF Viewer.

Are the dimensions measured before or after build-item transforms?

They are measured from the resolved build geometry, including supported build-item and component transforms.

Does a fitting result guarantee that I can print the file?

No. It is a size comparison only. Your slicer, chosen orientation, supports, printer margins and print settings still matter.
