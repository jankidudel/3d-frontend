3MF Manifold Checker

Check whether every edge in your 3MF build joins exactly two triangles. This checker counts open edges and edges shared by too many faces for each placed object, which is what slicers flag as non-manifold. Use it to locate a topology warning in a multi-object 3MF. It does not detect surfaces that pass through each other or decide how parts should be joined.

What this method reports

Finding Meaning
Open edge Only one triangle uses this edge, so the surface has a hole or gap.
Non-manifold edge Three or more triangles meet at this edge, often because of a duplicate face.
Number of pieces How many separate pieces each placed object has, added up across the build. This is not a count of errors.
Flipped face Two neighbouring triangles face opposite ways. The check cannot tell which side was meant to be outside.
Finished with no problems listed None of these problems were found. Things this check does not test (such as overlaps) are still unknown.

Each placed object is checked on its own, after applying the file's unit and the object's position and scale. Edges are matched by exact corner positions; nearby points are not merged. Zero-area and invalid triangles are skipped, but duplicate faces are counted. Pieces that share a corner count as one. The totals cover the whole build and do not say which object a problem is in.

This is one kind of check. Parts touching at a single point, or surfaces that cross, need a closer look even when no non-manifold edges are found, because this check does not look for overlaps. Don't merge separate parts just to get a lower piece count.

What to do next

Use which part has holes for holes, 3MF Repair to remove extra faces once you know they are duplicates, and mesh problem or placement problem when parts look fine but still trigger a warning. One stored object can be placed several times, so editing it changes every copy, which is different from deleting one placement. Keep the original and check the saved file in your slicer.
