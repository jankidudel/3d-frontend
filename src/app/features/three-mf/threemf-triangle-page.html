What the counter measures in a 3MF build

It counts the resolved geometry prepared for the print, not just triangles stored in source objects.

Why repeated build items affect the result

Each placed instance contributes its triangles because it is part of the build.

Triangle count, detail and slicer performance

More triangles can preserve curved detail but can slow slicing and file handling. Low counts suit simple shapes but can show faceting on curves. Nozzle size, layer height, scale and slicer settings also matter.

FAQ

Does it upload the file?

Yes, it uses InspectMesh’s secure processing flow and privacy behaviour.

Can a 3MF have multiple parts?

Yes. Multiple build items are supported.

Does more always mean better?

No. Triangle count is not a quality check.

Is triangle count a quality check?

No; use the related mesh checks too.
