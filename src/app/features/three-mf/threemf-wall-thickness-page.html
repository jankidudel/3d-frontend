How to read the result

The check uses the shapes, units and positions in the file. It does not apply slicer settings, so it cannot show how the slicer will split walls into perimeters and infill.

All placed objects, copies and nested parts are combined into one scene in millimetres. Thickness is measured at up to 2,000 points; points it could not measure, and areas it did not sample, are not included, so "no thin walls" is not a guarantee. Holes, neighbouring parts and gaps between parts need checking in the original program. Files using features the checker cannot read stop with an error rather than a guess.
