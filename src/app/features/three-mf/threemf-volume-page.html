One placed cube versus a repeated build

The one-placement cube declares millimetres and has 12 triangles. The two-placement control reuses that 20 mm cube at X=0 and X=40 mm. Analytical volumes are 8,000 mm³ for one cube and 16,000 mm³ for two separate disjoint cubes.

The 27 October 2026 local processor capture reports approximately 8,000 mm³ for one placement but unavailable volume for the two-component build, despite no listed mesh issues. This is the server processor code path executed locally, not a deployed endpoint observation. Supported placements resolve before the volume screen; their count does not guarantee a published aggregate total.

Downloading either example does not upload or calculate it. Select the file above and press Calculate 3MF volume deliberately to request a server result.

Use the result within its scope

Read the availability state first. Unavailable is not zero, and a failed or reportless attempt provides no completed volume measurement. Declared units and supported transforms affect physical geometry; an STL comparison must use the same selected scope and its stated millimetre convention. Separate shell sums do not perform a Boolean union or resolve an ambiguous cavity.

Optional solid mass uses available cm³ and your density. Use solid-mass guidance for those assumptions and complete slicer consumption for actual material planning. Follow the method-aware volume guide to interpret a missing or implausible value, then cost the actual sliced job.
