What the report means

Only objects actually placed on the build plate are checked. Shapes stored but not placed, features InspectMesh cannot read, and failed checks never count as "no problems". Check which parts are placed in the 3MF viewer, or find a missing part before cleaning the mesh.

Finding What it means Next action
Could not analyse this 3MF file The check did not finish. The file may be damaged, point to a missing part, or use a feature InspectMesh cannot read. Open it in the program that made it and export it again. A failed check is not the same as no problems.
Open edge A placed object has a hole or gap. It may be a missing surface or an intended thin sheet. Compare with the original design before filling it.
Non-manifold edge Three or more faces meet at one edge, often because of a duplicate face. Check the duplicate findings and that area; an extra face is fixed differently from overlapping parts.
Duplicate or degenerate triangle A face is stored twice, or has no area. Use 3MF Repair once you know what it will remove, then check the saved file again.
Flipped faces Neighbouring faces point opposite ways. This is not the same as dark shading in a viewer, or the inside wall of a hollow. Look at that area in the original model before flipping anything.
No mesh problems found None of these problems were found. Next, check size, walls, placement and the sliced layers. Overlaps, strength and print success are not checked here.

Questions about this check

Does this validate my slicer settings?

No. It checks the mesh only, not printer profiles, toolpaths, materials or every 3MF feature. Open the project in its own slicer to check settings.

Which geometry did this report analyse?

Every object placed on the build plate, with its position and scale applied. Shapes stored but not placed are ignored, because they will not print. The server checks each placed object separately; browser checks combine them, so results for overlapping objects can differ.

What happens to units and placed items?

The report uses the unit the file declares (millimetres if none) and does not change the file. The 3MF to STL converter, by contrast, writes millimetre coordinates into the STL, because STL has no unit.

Why can volume be unavailable when the mesh check completes?

Volume is only shown when the build is one valid, connected part. Two separate, perfectly good cubes therefore get a blank volume. Blank never means zero material.

Where is my file processed?

Pressing Check uploads the file to our server. Viewing it or running 3MF preflight happens in your browser and uploads nothing. Read how the checks work before choosing a workflow for confidential designs.
