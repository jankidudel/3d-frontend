STL Dimensions Checker

Measure how big your STL is: width, depth and height. STL files do not store units, so a model drawn in inches can import 25.4 times too small. Pick the unit the model was designed in, compare one dimension you know, and scale it if needed before you slice.

What should I do with this size?

Result What to do
A dimension you know matches Check it fits your printer in the orientation you want, then check the placement in your slicer.
Every dimension is off by the same factor (like 25.4 or 10) Work out which unit it was designed in before fixing the size.
One feature is the wrong size, but the overall size is right Fix that feature in CAD; don't scale the whole model
It only just fits your printer Check supports, brim and any no-print areas of the bed in your slicer
Value Meaning
Size in file units How far the model extends along an axis, in the file's own numbers. STL has no unit, so these are not yet mm or inches.
Real size The size in the unit you chose, which a dimension you know should confirm.
Suggested scale Target size divided by current size; the other axes change by the same amount.
Printer fit Whether the model fits your printer's listed build volume, turning it in 90 degree steps. Still check the placement in your slicer.

STL files store numbers without units, so the real size depends on the unit you choose. The printer fit uses the printer's listed build volume, without extra room for brims or no-print areas.
