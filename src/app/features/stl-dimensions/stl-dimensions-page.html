STL Dimensions Checker

Measure how big your STL is: width, depth and height. STL files do not store units, so a model drawn in inches can import 25.4 times too small. Pick the unit the model was designed in, compare one dimension you know, and scale it if needed before you slice.

STL geometry is stored as unitless coordinates, so STL files do not reliably contain unit metadata. You choose how those coordinates should be interpreted after measurement.

What should I do with this size?

Result Next action
The known reference dimension agrees Check the intended orientation and nominal usable envelope, then verify the sliced placement.
All dimensions differ by one plausible unit factor Establish a known dimension and source unit before choosing a correction.
One functional feature differs while overall size agrees Inspect that feature or source CAD; do not globally resize
A nominal printer comparison is close Check actual supports, brim and bed exclusions in the slicer
Value Meaning
Coordinate span Maximum minus minimum on a measured axis; it has no inherent physical unit in STL.
Interpreted size The span expressed under the unit assumption supported by your source dimension.
Proposed proportional scale Target span divided by current span; other axes change by the same factor.
Nominal printer comparison A comparison within the implemented orientation and bed assumptions; the final sliced placement still needs review.

Coordinate spans have no inherent physical unit in STL. Interpreted size follows your chosen assumption. A nominal printer comparison tests only the implemented orientation and bed assumptions, not a physical fit tolerance.
