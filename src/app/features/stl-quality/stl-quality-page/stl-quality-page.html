Turn a finding into one next action

Report finding Next action
Boundary edge Use the boundary checker and inspect whether the opening is intended.
A visible wall with no enclosed thickness Compare the open sheet and closed plate controls before changing slicer settings.
Over-shared edge Read the topology correction workflow; do not guess the extra face.
Exact duplicate or degenerate face Review the source and the standard cleanup report, then recheck its downloaded copy.
Winding conflict Compare the known orientation controls before changing a component.
No listed blockers or an uncertain shape Check the local preflight, source CAD and the selected slicer preview. Inspect hidden internal faces when the outside looks right but interior layers do not.

The server compares exact stored coordinates and excludes degenerate triangles from edge counts. Its report components join through shared vertices; local STL Repair part selection uses shared edges. A clean report means only that supported checks found no listed blockers. Volume is unavailable for open or inconsistent reports; even a reported closed-mesh value cannot establish that untested spatial crossings or cavity intent are correct. If two closed surfaces overlap despite a clean edge count, compare them with the crossing-surface guide before changing the source model.
