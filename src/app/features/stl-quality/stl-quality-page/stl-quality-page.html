STL Quality Checker

Not sure what is wrong with your STL? Start here. This is the all-in-one check: it looks for holes (open edges), edges shared by too many faces, duplicate and zero-area triangles and flipped faces in one report. If you only need to know whether the model is closed, the watertight checker is quicker. A clean report means these problems were not found, not that the print is guaranteed.

Choose your file

Choose an STL file up to 25 MiB. Pressing Check uploads it to our server for analysis; just viewing it does not. Read the privacy policy before uploading a private model.

Try an example file first

Downloading an example does not upload anything. Each is a 20 mm cube (STL has no units, so open them as millimetres) with one known problem, so you can see what each finding looks like.

Example What the report shows
Closed cube 12 triangles and no problems. A clean result, not a guarantee it will print.
Missing-face cube 10 triangles and four open edges: one side of the cube is missing.
Duplicate-face cube 13 triangles: one duplicate triangle, which creates three non-manifold edges.
Malformed file The file can't be read, so you get an error. That is not a clean result.

What to do about each finding

Finding Next action
File can't be read, or no report You have no result, not a clean one. See STL file won't slice and the error message before trying again.
Open edges (holes) Use the watertight checker and read about watertight STLs before filling anything. A designed hole or channel is not an error.
A wall that looks solid but has no thickness Compare the sheet vs plate examples before changing slicer settings; the fix is usually in CAD.
Non-manifold edge Read the non-manifold fix guide; don't guess which face is extra.
Duplicate or zero-area triangle Run STL Repair cleanup, read its report, then check the downloaded copy again.
Flipped faces Compare the flipped-normals examples before flipping a whole part.
No problems found, but something looks wrong Check the STL preflight, the CAD model and your slicer preview. Look for hidden internal faces when the outside looks right but the inside slices wrongly.

How it works: the server compares exact corner positions and skips zero-area triangles when counting edges. It counts pieces that share a corner as one (STL Repair's piece selector groups them slightly differently). A clean report means none of these problems were found, not that the model is perfect. Volume is left blank for open or inconsistent models, and even a volume cannot tell you whether overlapping surfaces or hollows are right. If two closed parts overlap even though the edges look clean, see the overlapping surfaces guide before changing the model.
