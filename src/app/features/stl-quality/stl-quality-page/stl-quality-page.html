Catch common STL issues before printing

How it works

Upload an STL and InspectMesh checks its triangles, edges and surface orientation for common mesh problems.

What the results mean

Open edges and non-manifold edges can prevent a clean solid. Duplicate or degenerate triangles add invalid geometry, while orientation issues can affect inside and outside calculations. Ready for slicing means these checks found no listed mesh blockers, not that every printer setting is correct.

FAQ

What is an open edge?

It is an edge used by only one triangle, often indicating a hole.

What is a degenerate triangle?

It has no usable area because its vertices collapse together or lie on a line.

Should I repair duplicate triangles?

Usually yes, because overlapping faces can confuse downstream tools.
