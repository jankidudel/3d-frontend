How to act on a sampled result

Observation Next action
Measured sample below threshold Inspect that geometry and the same sliced region. Compare nominal line widths only after checking the actual wall.
No measured sample below threshold Review unmeasured locations and critical features that finite sampling can miss.
Unmeasured sample, possibly alongside a thin sample Inspect open, degenerate or ambiguous geometry in CAD and the mesh viewer.
No valid measurement Check unit, geometry and method limits; no zero or success is implied.
File could not be analysed Choose a supported nonempty STL within the file limit and try again.

Method boundary

The checker selects up to 2,000 triangles across input triangle order and casts one inward normal ray from each centroid. Degenerate faces and rays without an accepted opposing hit remain unmeasured. Unsampled triangles receive no estimate. A ray may hit another body, so this is neither a per-part result nor a whole-model minimum certificate. Read the sampling method.
