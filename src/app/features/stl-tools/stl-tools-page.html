Choose a path by task

  • Starting with an unfamiliar file? Run STL Print Preflight, then follow the finding to a focused check.
  • Suspect an open surface? Use the STL Watertight Checker and inspect the hole before capping it.
  • Found detached pieces? In STL Repair, all pieces start kept. Keep largest part proposes a reversible surface-area selection; review it before downloading. First identify intended shells before removing any.
  • Need an intentional cut between parts? Use the STL Splitter for a supported planar cut, then verify both exported meshes. Use the split diagnosis guide when the input, plane, contour or processing stage is rejected, or the alignment-pin guide when planning the separate assembly. An intentional cut is a different task from removing detached fragments.
  • File too large? The local reducer compares binary re-encoding with lossy triangle reduction; read the size-reduction decision guide before choosing a target.
  • Concerned about non-manifold edges or disconnected shells? Run the STL Manifold Checker; it checks different topology findings from the open-edge check.
  • Want to rotate and inspect the model before deciding what to do? Open the Free STL Viewer.
  • Need the model's overall size or printer-fit dimensions? Use the STL Dimensions Checker; confirm the unit assumption before interpreting measurements.
  • Need to change size without changing proportions? Use the STL Scale Tool and verify the resulting dimensions.
  • Checking whether thin regions may need attention? The STL Wall Thickness Checker provides an approximate sampled preflight, not a guarantee of printable walls.
  • Need a quick measure of mesh complexity? The STL Triangle Counter reports the triangle count; it does not reduce the file.
  • Estimating solid-model volume or material mass? Use the STL Volume Calculator; the estimate depends on a valid closed volume and selected material density.
  • Need a basic 3MF with an explicit unit for the STL coordinates? Use the STL to 3MF Converter.

STL tool FAQ

What is an STL file?

An STL describes a model surface as a set of triangles. It is common in 3D printing, but it does not reliably store design units.

Should I check an STL before slicing?

Yes. Open edges, non-manifold geometry and unexpected scale can lead to confusing slicer results.

Does a clean check guarantee a successful print?

No. Printer calibration, supports, material and slicer settings still affect the physical result.
