Find the First Failing Step faq: - question: Can a mesh check explain every missing extrusion? answer: No. A valid mesh can lose a narrow feature under a particular slicer profile; inspect the first affected layer. - question: Does a successful slice prove the geometry is correct? answer: No. Inspect the actual layers, dimensions and intended openings. A slicer can produce toolpaths for a model whose design intent was changed. ---

First identify whether the STL fails to open, imports at the wrong size, or loses geometry only after slicing. A mesh finding, a slicer-profile outcome and a physical print are three different things. Save the source and change one cause at a time.

Quick triage

  1. Cannot open or empty: verify the export and triangle count.
  2. Surprising size or position: compare known dimensions and source units.
  3. Gaps or missing layers: look for a surface finding, then compare layers.
  4. Detached objects: identify every intended piece before selecting removals.
  5. Valid mesh but omitted thin extrusion: inspect the profile and first affected layer.
  6. Slow import: inspect triangle count before reducing a copy.
Symptom Confirming test Next action
File is rejected or blank Open it in the STL viewer and check whether complete triangles exist. Re-export from source if malformed or empty; do not ask a mesh repair to recreate missing design data.
Import is huge, tiny or outside the usable bed Measure a known span and the bounds in the dimensions checker. Correct the unit assumption or follow the off-bed placement control, then confirm the final preview.
Opening or missing wall in layers Run the open-edge check; the owned open-face cube has four boundary edges. Reconstruct a known missing surface in CAD or a mesh editor and recheck.
Unexpected join, branch or filled region Compare manifold and overlap evidence in preflight with the source design. Compare the closed-channel slicer control, then correct a failed Boolean or overlap in the source. A clean edge count alone is insufficient.
Extra separate object Review every component in STL Repair. Keep intended pieces; remove a confirmed fragment only by an explicit retained-copy download.
Thin feature disappears despite a valid import Compare source width with sliced paths under the chosen perimeter generator and line width. Review the thin-wall experiment; redesign or adjust a tested profile rather than running unrelated mesh cleanup.
Import stalls Check triangle count and test a saved copy in the same slicer. Re-export from CAD or simplify conservatively and compare detail.

When the mesh check and slicer disagree

A clean supported topology result does not cover every self-intersection, tiny extrusion or unsupported region. Find the first incorrect layer and compare it with the source model. A surface defect calls for geometry review; a narrow feature omitted under one profile calls for a profile or design decision. For a warning about an unsupported layer, follow the floating-region control. Neither result certifies physical print performance.

A retained slicer control

The owned three-bar STL was sliced with PrusaSlicer 2.9.6 at 0.4 mm nozzle, 0.45 mm extrusion width, 0.2 mm layer height, two perimeters, zero infill and thin walls disabled. In the retained second-layer G-code preview, Classic produced four extrusion moves at one bar position; Arachne produced six moves at three bar positions. The wall-thickness guide has the files, settings and full interpretation. This software result shows why a successful geometry import can still omit a feature. It is not a tested physical print or a universal minimum feature size.

Finish by reopening the actual saved STL and inspecting all affected layers in the slicer and printer profile you intend to use. For a broader preparation sequence, see the model-ready checklist.
