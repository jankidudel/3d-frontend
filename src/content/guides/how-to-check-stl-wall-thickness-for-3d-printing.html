Confirm the STL's physical size before interpreting a wall result. Then choose a review threshold, inspect measured and unmeasured samples separately, and verify critical features in the source model and sliced layers.

1. Set the scale before the threshold

STL stores coordinates without a declared physical unit. A cube spanning one coordinate unit could be read as 1 mm or 25.4 mm under different assumptions; neither proves the author's intended size. Check a known dimension in STL Dimensions Checker. In the STL Wall Thickness Checker, choose the STL coordinate unit. Its Review threshold and reported samples use that selected unit. A physical 0.04-inch target equals 1.016 mm; enter 0.04 with inches selected or 1.016 with mm selected. Changing the unit clears the earlier result and requires a new run.

2. Run the known thin-bar control

Download the closed thin-bar STL or load it on the checker. The three designed bars are 20 mm long, 10 mm high and 0.3, 0.45 and 0.9 mm wide. Select mm, enter a 1.2 mm review threshold and run the local analysis. The current centroid-ray implementation, checked 16 October 2026, returned:

The source widths and measured ray distances answer different questions. Faces along a long dimension can return a larger distance; the roughly 0.3 mm sample includes the ray offset and is not a metrology accuracy claim. The result samples these 36 triangles, not every point in each bar. Reproduction settings and the original slicer exports are retained with the thin-feature example.

3. Read the result without over-interpreting it

Observation What to check
One or more measured samples below threshold Find the marked region; compare intended CAD material with the sliced paths. The count is rays, not separate defects.
Some sampled locations unmeasured Inspect open or ambiguous geometry. An absent opposing hit is neither zero thickness nor a pass; it can coexist with thin measured samples.
No measured sample below threshold Review critical details and unmeasured locations. Finite input-order sampling can miss a narrow rib.
Unit changed Rerun after confirming a known dimension. The old result is invalid for the new physical interpretation.

The open-face cube is an optional no-hit control. At the same mm assumption and 1.2 mm threshold, the current checker attempted 10 samples, measured eight and left two unmeasured; none of the measured samples was below threshold. Removing one face does not make every ray miss: inspect which sampled directions still find another surface. Use a visual cross-section when an internal passage is the concern.

4. Change the feature that needs changing

In the source CAD, increase a specific wall or rib when its role requires more material. Global scale changes every dimension: a 1.2 mm wall scaled to 75% becomes 0.9 mm, while a 10 mm hole becomes 7.5 mm. That is dimensional arithmetic, not an observed print. Prefer a local parametric edit when holes, mating faces or clearances must remain fixed. Use the wall-thickness decision guide to judge the feature's process and use.

5. Confirm the saved copy and sliced layers

  1. Name the critical region, such as the rib beside a mounting hole. Export a new copy, confirm its physical dimensions and topology, then find that same region in the reopened STL.
  2. Compare the source material width with the sampled result at that region. The review threshold only flags measured rays; it does not configure line width, perimeter generation or any other slicer setting.
  3. Slice the saved copy with the intended profile and inspect corresponding model paths through every affected layer. Separate travel and skirt paths from paths that represent the feature.

In a retained PrusaSlicer 2.9.6 software experiment on the thin bars, Classic and Arachne produced different second-layer paths under recorded settings. The full comparison explains its settings and limitations. Neither software preview is a physical print test.

For lettering, distinguish solid strokes from the empty counters inside letters and separate XY width from Z relief. Follow the lettering checks; a sampled material ray is not a groove-width measurement.

On the exact T1 control, the current local method measured all 500 selected face-centroid rays: 32 were below a 0.4 mm review threshold and none were unmeasured. Named O-left side faces returned about 0.24999 mm, while other directions crossed the longer material span. In T1-C, no model paths occur in the O region above the plaque; T2's local widening restores them. This is a matched source/slicer observation, not a threshold configuring the slicer or a minimum-wall proof. The implementation record identifies source hashes, sampled triangles and settings.
