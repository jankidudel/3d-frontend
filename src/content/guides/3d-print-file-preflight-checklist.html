Preserve the original, change only what matters, and re-check the result. - question: Is 3MF better than STL for preflight? answer: 3MF can declare units and represent placed build items, while STL is a simpler unitless mesh. Both still need geometry and slicer checks. ---

Use the right evidence for each row

Run STL Print Preflight or 3MF Print Preflight for supported geometry screens. Record the actual method and settings. STL requires an assumed unit; a 3MF resource count is not the placed-item count. No printer profile means fit is unknown, not passed.

A collection report can retain completed, failed and cancelled files separately. Do not average a failed input into a clean collection score. A new revision needs a new check, even if its filename matches an earlier one.

Optional functional-interface review

Use the existing finding/next-action notes for the exact counterpart or drawing, named critical dimensions and hole role, seat or installation access. Retain the source and mesh checks separately from the required physical acceptance evidence. If the role or drawing is missing, record Unknown and clarify it; automatic mesh repair cannot supply that requirement.

Stop and choose a specific next action

Stop when intended scale, geometry or required parts cannot be established. Inspect an opening before filling it and identify a disconnected part before removing it. Preserve the original and recheck the saved result after a supported change. Use the STL finding interpretation guide for diagnostic branches, or the cross-format readiness guide for the reasoning behind each stage. This checklist records the decision; it does not duplicate that explanation or certify a physical print.
