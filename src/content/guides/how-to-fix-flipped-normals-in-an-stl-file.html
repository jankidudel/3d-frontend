A dark face in a viewer is not proof that its STL triangle order is wrong. Check a saved copy's winding against neighbouring faces and a known outside surface. Reverse an entire closed component only when its orientation is consistently inward; treat a local reversed patch and an open or intersecting model as different cases.

Is it display shading or triangle winding?

STL stores a facet-normal vector and three ordered vertex positions. InspectMesh's orientation check uses the vertex order around shared edges, not the stored normal vector or viewer lighting. Two neighbouring triangles should traverse their common edge in opposite directions. A model can pass that consistency test while its whole closed shell faces inward. A two-sided viewer may also show a single open sheet as a wall.

Three known cubes

Each control has identical 0–20 coordinate bounds and 12 triangles. The values below are measured with the InspectMesh processor, not physical print results. STL itself declares no unit.

Download Observed check Supported action
Outward reference Zero open, over-shared and winding-conflict edges Keep as orientation baseline.
One reversed face Four winding-conflict edges; no open edges Standard cleanup corrected the two patch triangles in the tested copy; download that result.
Whole inward shell Zero winding conflicts, zero open edges Compare against a known outside and deliberately reverse the full component in source CAD or a mesh editor. Standard cleanup offered no file.

The server repair report for the reversed-face control records two orientation corrections, 12 output triangles, unchanged 20 × 20 × 20 bounds and no remaining winding conflicts after reparse. The whole-inward control remains consistent under the edge-direction test; the reported absolute volume cannot reveal which side the designer intended. A separate stored-normal-only control changes one normal record but produces zero winding conflicts.

Choose a local or whole-component correction

For a small reversed patch on a closed, otherwise coherent shell, inspect the patch and use a targeted face-orientation correction. The standard STL cleanup explicitly uploads the chosen file and attempts consistent winding only in closed supported regions. Its report tells you what it changed; it does not infer the intended global outside. For an inward but consistently wound closed shell, review the source design and reverse that entire component deliberately. If the mesh is open, contains duplicate faces or has crossing surfaces, resolve those structural questions before trusting any orientation operation.

Recheck the saved output

Save under a new filename, then run the quality check on the downloaded bytes. Compare triangle count, bounds, boundary and over-shared edges, winding conflicts and the first affected slicer layers. Recalculation does not fill a hole, union shells or prove printability. Stop when the intended outside cannot be established from the original design.
