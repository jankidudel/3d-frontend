To scale a 3MF, open it in your slicer, select the objects you want to resize, change their scale or size, and save a new project. The difference from an STL is that a 3MF can hold several objects, linked copies and their positions, so decide first whether you are resizing one part or the whole layout.

Before you start

  • Keep the original 3MF and write down the sizes you need.
  • If the size is wildly off, check the 3MF unit first; a scale fix may not be needed.
  • Measure the current build with the 3MF dimensions checker. InspectMesh measures 3MF files but does not edit them.

Scale a 3MF in PrusaSlicer

These steps follow Prusa's object manipulation panel and instances documentation for the 2.9 family, reviewed 26 October 2026. We have not tested them in an installed copy, so check the labels in your version.

  1. Open the 3MF in PrusaSlicer and note your version.
  2. In the object list, see which items are separate objects, linked copies (instances) of one object, or parts of one object.
  3. Select what you want to resize. In the object manipulation panel, enter a Scale factor or a Size with uniform scaling kept on. For a 40 x 20 x 10 mm object, 150% (or X = 60 mm) gives 60 x 30 x 15 mm.
  4. Check every copy. Linked instances can share the same scale, so resizing one may resize them all. Prusa's instance documentation explains how to make a copy independent if you need to change only one.
  5. Save as a new 3MF, reopen it and confirm the sizes, objects and settings.
  6. Slice again and check that everything still fits the bed with supports and brim.

Resizing the layout vs resizing each part

Example: two 20 mm cubes, the second placed 40 mm along X, so the layout spans 0 to 60 mm. Scaling by 1.5 gives different results depending on what you scale:

What you scale Layout width Why
Nothing (original) 0 to 60 mm Two 20 mm cubes, 40 mm apart
The whole layout 0 to 90 mm The cubes and the gap between them both grow
Each cube, positions unchanged 0 to 70 mm Each cube is 30 mm, but the second still starts at 40 mm

These are calculations; your slicer may scale around a different point. Use the 3MF viewer to see which objects and positions the file contains. After scaling, re-check room for brims and supports and, for round beds, round bed fit.

When not to scale

Scaling changes holes, walls and clearances along with the outside size. If the part must still fit screws or another part, change the size in CAD and keep those features fixed. Different scale factors per axis turn circles into ovals.
