Inspect the declared unit and placed dimensions before scaling a 3MF. Then change the intended object or arrangement in a slicer or modelling application and save a new project. InspectMesh's dimensions checker measures the build; it does not become a 3MF editor because it links to this guide.

PrusaSlicer procedure: documentation-based, 2.9 family

This procedure follows the official Object manipulation panel and linked-instance documentation, reviewed 26 October 2026. The consulted instance documentation is labelled for the 2.9 legacy family. No installed application was exercised for this article; confirm your version and control labels before use. No screenshot or observed PrusaSlicer output is claimed.

  1. Keep the original 3MF and note intended physical dimensions. Check unit and transform context if the size is unexpected.
  2. Open the package in its producing application or a compatible installed PrusaSlicer version. Record that version.
  3. Inspect the object list: identify independent objects, linked instances and parts of one object. Determine which scope should change.
  4. Select that scope. In the Object manipulation panel, use Scale factors or Size with uniform scaling maintained. For an independent 40 × 20 × 10 mm object, target a 60 mm X size or final 150% scale. Expected spans are 60 × 30 × 15 mm.
  5. Inspect every affected copy, placement and important feature. Linked instances can share scaling; do not assume one selected copy is independent. The official instance workflow describes separating an instance when an independent change is required.
  6. Save a new 3MF project. Reopen those saved bytes and confirm dimensions, intended items and assignments.
  7. Slice again with the intended profile. Check actual layers, support footprint and usable bed space before accepting the job.

A shape-aware fit screen applies to the selected resolved envelope, which may include several placed build items. A centred circular bound does not validate their current source positions. Scale may change relative layout as well as hardware dimensions; retain declared units and placement scope. Keep physical process allowances separate. InspectMesh does not save a native 3MF project with every vendor setting, orientation and scale applied.

Scaling an arrangement differs from scaling local objects

Analytical illustration: two 20 mm cubes have local X = 0 to 20; the second placement translates X by 40 mm. Overall X is 0 to 60 mm. These operations differ:

Operation Overall X bounds Reason
Original arrangement 0 to 60 mm Unchanged 20 mm cubes and a 40 mm placement offset
Whole resolved arrangement × 1.5 about origin 0 to 90 mm Both geometry and the placement distance scale
Local cube coordinates × 1.5; translations unchanged 0 to 70 mm Each cube becomes 30 mm; the second still starts at X = 40 mm

These are calculations, not observations of a particular slicer pivot. Preserving assembly relationships and resizing independent parts are different requirements. Name the selected scope and observed application behaviour separately; the placed-item viewer helps inspect the source.

Stop when a feature must stay fixed

A uniform transform changes holes, walls and mating clearances. If the outer size must change while a mounting interface remains fixed, edit source CAD rather than resizing the entire mesh. Nonuniform scaling can distort circles. Use the dimensions checker to measure the new supported build; it does not save edits or establish printed fit.
