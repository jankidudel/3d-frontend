Read the exposed-boundary result for the geometry the method actually checked. Zero detected open edges supports a closure finding, but it does not establish that a 3MF is free of duplicate faces, over-shared edges, intersections or incorrect placement.

Use a closed-but-defective package as a counterexample

A 3MF is watertight when each placed part has no open boundary edges. Check every part of a multi-object build separately, decide whether any opening is intended, and remember that a closed surface can still contain other faults.

The owned repeated-face package has no exposed boundary in the retained local .NET processor check (24 October 2026), but it has one duplicate triangle and three over-shared edges. Read the retained local report: zero open edges did not make this mesh free of findings. Establish the intended cube surface before selecting duplicate cleanup. Repeating a whole valid item in a build is a different case from repeating a triangle inside its resource.

The retained report comes from the repository processor method, not a verified production endpoint revision. Its fixture hash, reproduction command and method are retained in the evidence provenance. Run the 3MF Watertight Checker separately to obtain a current server result; it uploads only after an explicit check action.

Decide what the opening represents

An exposed mesh boundary and an opening in the shape are different things. A thick-walled cup can have an open mouth while its inner and outer walls meet around the rim as a closed material surface. An uncapped single sheet can have exposed boundary edges. Inspect the intended surfaces before choosing to cap anything.

Interpret separate parts independently from closure

Several placed items can be valid separate parts. A zero-boundary result does not say whether those parts should be joined or whether their placements overlap. Preserve the required items and inspect their intended arrangement in the source application.

The server method checks each supported placed build item independently, using exact endpoint coordinates after unit conversion and transforms, then aggregates counts. Its aggregate report does not locate a defective resource for you. Geometry sharing a point can belong to one vertex-connected component without forming an acceptable solid connection. Local combined-build checks can differ, so retain the method with the result.

Decision Action
A required surface is missing and its shape is known Repair a copy in source CAD or an appropriate editor, then reopen and recheck it.
The intended surface cannot be established Return to the author or producing application.
The finding is a redundant triangle rather than a missing surface Review supported local 3MF cleanup; removing a face does not invent a missing one.
No boundary was found but other findings remain Investigate those findings with the relevant topology or quality method.

Reopen the saved package, confirm required items and dimensions, repeat the relevant checks and inspect the affected slicer layers. A completed closure check does not settle wall strength, supports or process settings. Use the repair guide when selecting a correction and the topology guide when edge sharing is the concern.
