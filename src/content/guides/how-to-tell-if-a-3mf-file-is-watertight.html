--- title: 'Which Part of My 3MF Has Holes? | InspectMesh' description: 'A 3MF is watertight when every object in it is closed. Check each object of a build separately and tell real holes from openings.' slug: how-to-tell-if-a-3mf-file-is-watertight eyebrow: 3MF mesh guide heading: How to Tell Which Part of a 3MF Has Holes ---

A 3MF is watertight when every object placed in it has a closed surface with no open edges. Because a 3MF can hold many objects, check each one separately: one bad part can make the whole build fail to slice. The 3MF Watertight Checker counts open edges per placed object.

Check each object, not just the build

InspectMesh checks every placed object on its own, after applying the file's unit and each object's position and scale, then adds up the results. The total tells you whether there are holes, but not which object they are in. To find it, open the file in the 3MF viewer and look at the objects one at a time, or export the parts separately and check each.

Separate objects in a build are normal. A closed result does not say whether parts should be joined, or whether two objects overlap. Parts touching at a single point may be counted as connected without forming a real joint. The browser and server checks can group pieces differently, so note which one you used.

Closed does not mean error-free

Our example 3MF with a repeated face has no open edges, but it still has one duplicate triangle and three non-manifold edges (see the saved report from 24 October 2026 and its test details). Placing the same whole object twice in a build is fine; storing the same triangle twice inside one object is not. For a current result, run the watertight checker yourself; it uploads only when you press check.

Is it a hole or an opening?

A thick-walled cup has an open top, but its inner and outer walls meet at the rim, so the mesh is closed. A single paper-thin sheet has open edges all round. Look at what the shape is meant to be before filling anything.

What to do next

Situation Action
A surface is missing and you know its shape Fix a copy in CAD or a mesh editor, then reopen and recheck it.
You cannot tell what the surface should be Ask the designer or open the file in the program that made it.
The problem is an extra triangle, not a missing one Try 3MF Repair. Removing a face does not create a missing one.
No holes, but other problems are reported Check them with the 3MF non-manifold guide.

After fixing, reopen the saved file, confirm all objects and sizes are still there, check again and look at the sliced layers. A closed surface does not prove the part is strong enough or needs no supports. For choosing a fix, see how to repair a 3MF.
