Calibrate from repeatable machine behaviour towards a stable material profile, then validate the dimensions and features the part actually needs. Change one named value at a time. Stop and return upstream when an earlier check becomes inconsistent; a later compensation should not hide that fault.

Separate machine, material and model decisions

Machine variables include motion, offsets, extruder mechanics and firmware. Material/profile variables include temperature, cooling and flow. Model and process choices include orientation, walls, supports and seam placement. Choosing a less-visible start location is a placement decision, not proof that filament delivery needs calibration. Preserve a known-good profile and back up adjustable values before editing them.

One ordered calibration workflow

Follow the exact printer, firmware and slicer manufacturer's procedure where it differs from this general sequence. Begin with identified, suitably conditioned material, an appropriate profile and an undamaged build surface. Electrical damage, thermal faults or damaged motion hardware need qualified attention, not tuning around the symptom.

Prerequisites, evidence and stop/return checkpoints
Stage Evidence before proceeding Stop or return when
1. Safety and mechanics Secure fasteners, belts and pulleys; clear filament path/nozzle; smooth repeatable motion; applicable firmware and end-stop checks. Motion slips, hardware is loose or a safety fault appears.
2. Bed and first layer Repeatable surface preparation, offset and first-layer result in relevant bed regions. Contact or adhesion varies before the intended measurement.
3. Extruder motion Manufacturer-appropriate commanded-versus-actual feed comparison, repeated before any adjustable machine value changes. Feed varies or drag/slipping makes the comparison unreliable. Use the feed-versus-flow workflow.
4. Material baseline One identified spool, stable condition and temperature chosen using applicable material/profile guidance. Material condition or delivery changes between controls.
5. Profile flow Repeatable results from the manufacturer's prescribed wall or surface test after feed is reliable. A large or inconsistent correction suggests a wrong test basis, width or unresolved feed fault.
6. Transition behaviour Relevant pressure/retraction comparison with stable flow; retain the unchanged control. A change creates weak or unstable extrusion. Restore the stable profile before continuing.
7. Dimensions and fit Direction-labelled repeated readings from purpose-built axis, bore or mating-feature coupons. Repeated readings vary more than the intended change. Investigate rather than infer a correction factor.
8. Application validation Reviewed source and slice, followed by a representative feature under the final conditions. The actual requirement remains unmet; return to its responsible stage.

Reprint the unchanged control after a setting change. If a new flow value changes hole fit, confirm that flow test before compensating the hole. Changing temperature, speed, flow and dimensions together cannot identify which change helped. Calibration improves evidence; it certifies neither strength nor surface quality.

Route the symptom to a focused answer

Observation First distinction Next step
Whole-part axis error Comparable repeats and sizes support a scale question. Shrinkage workflow and axis worksheet.
First-layer flare The base differs from middle/upper readings. Local base diagnosis.
Restricted bore Axis, upper arc, seam or support contact changes the restriction. Locate the bore restriction before local compensation.
Mating parts do not fit Chosen clearance differs from local process error. Tolerance and clearance with the fit worksheet.
Start/stop mark on a critical face Location differs from transition quality. Seam placement; use feed/flow evidence only for an actual delivery question.
Existing flat top needs a different appearance Normal pattern differs from additional processing. Top-fill pattern versus ironing.
Fit changes after initial validation Condition, loading or elapsed time may differ from the cooled reference. Investigate measurement state and time under load before changing firmware, flow or scale.
Inconsistent repeats Instrument, conditioning or process varies. Keep raw readings and return upstream; do not average away the instability.

Keep one calibration record

  • Date, printer, firmware, extruder hardware, nozzle and build surface.
  • Material, spool condition and relevant environmental conditions.
  • Slicer/version, saved profile and source file/revision.
  • Temperature, speed, layer height, line width and orientation for the test.
  • Test method, instrument, raw direction-labelled readings and retained photographs or coupons.
  • Original value, one changed value, result and any reason to revert.

Separate machine-level values from material/profile values. For an appropriate repeatable single-wall test, the flow calculator provides transparent starting arithmetic; it cannot choose or measure the test. Recheck the affected stages after hardware, nozzle, firmware, material or profile changes, or actual drift. Stable evidence does not expire on a calendar.

Finish with representative validation

Select a small model containing the feature that matters: a bridge, vertical hole, thin wall, mating pair or loaded clip. Inspect file dimensions and mesh with STL preflight or 3MF preflight, then review placement, supports and the actual layer paths. Print with the recorded profile and assess the relevant requirement. A generic cube cannot validate every future geometry, and calibration does not repair missing source surfaces.
