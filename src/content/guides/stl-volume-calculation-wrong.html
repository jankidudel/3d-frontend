First confirm units and whether the mesh supports a solid-volume calculation. Open boundaries, inconsistent winding and ambiguous shells can make a number meaningless. InspectMesh collection reports use an unavailable result for failed volume screens rather than displaying zero as if a solid had been measured.

Interpretation and scaling give different reproducible numbers

Operation on the closed control Linear span Volume interpretation
Original, mm assumption 20 mm 8,000 mm³
Same original bytes, inch assumption 508 mm 131,096,512 mm³ = 8,000 × 25.4³
Save a 150% scaled copy; reopen as mm 30 mm 27,000 mm³ = 8,000 × 1.5³
Face-removed copy, mm assumption 20 mm bounds Unavailable, not zero

Actual scale export/re-import retains 12 triangles and gives 30-coordinate spans. The 3.375 volume factor applies to a valid closed solid, not a reliable volume for an open surface. Use the same known control to check the receiving application's unit before trusting a volume or using it for material planning.

Signed volume and winding

A triangle mesh calculation accumulates signed tetrahedron contributions relative to the origin, divided by six. Reversing every face of a consistent closed shell reverses the algebraic sign. That negative sign indicates orientation in this calculation, not negative physical material. Inconsistent local winding can cancel contributions and should be investigated instead of hidden by taking an absolute value immediately.

The collection checker first screens edge incidence, degenerate/duplicate triangles, winding conflicts and connected shells. It reports the magnitude for a supported, consistently wound single closed shell. It does not expose a negative physical-volume result. Multiple shells deliberately fail its conservative solid interpretation; self intersections are not checked, so passing these screens still does not certify a valid solid.

Observed result Check next Decision
Unavailable Boundary edges, degenerates, duplicates, winding and shell count Correct known faults; never substitute zero
Implausibly large/small Known linear dimension and STL unit assumption Correct scale only after confirming intended units
Negative in another application Its signed-volume convention and global winding Inspect orientation; distinguish raw signed sum from physical volume
Zero or tiny on a nonempty model Open surfaces, cancellation, self intersections or negligible extent Return to CAD if solid interpretation is unclear
Several overlapping shells Intended union, cavities and intersecting surfaces Do not add their volumes blindly

Name the method and distinguish a passage from an unfinished surface

Record which tool produced the value. The local collection screen and server processor use their own connectivity and validity policies. Agreement on dimensions does not imply both methods will publish the same volume state. Neither a positive signed sum nor a closed boundary proves the intended solid interpretation.

Owned control, mm convention Analytical expectation Actual observations by method

The latter is the server's processor code path run locally, not a deployed endpoint observation. A designed passage is empty space bounded by intact material surfaces, unlike a missing mesh face. These controls establish no physical flow, drainage or strength.

For a designed cavity, follow the hollow-design decision, then inspect its interior with visual clipping. Do not subtract unsigned arbitrary shell volumes to infer a cavity.

Recheck after a correction

  1. Keep the original; record bounds and the application/unit settings that produced the number.
  2. Run topology and dimension review; locate the actual fault.
  3. Correct the source solid or a clearly understood mesh defect on a copy.
  4. Compare revised surfaces and verify known dimensions, not just total volume.
  5. Inspect the resulting solid and sliced layers in the intended application.

Solid volume is not slicer material use

Geometric volume assumes a solid interpretation. Slicer material includes walls, infill, supports and purge, according to settings; hollow interiors may use less while supports add material. Use the actual sliced consumption for a quote or spool decision. Read filament-use guidance and avoid using model volume as a complete job estimate.
