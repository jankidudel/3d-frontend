To repair an STL, first find out what is actually wrong with it, then apply the fix for that error only. Duplicate faces, holes, flipped faces, loose parts and overlapping solids each need a different repair. Keep the original, save each repaired version as a new file, and check the copy you will slice.

Which fix for which error

Find your errors with the STL Quality Checker (see how to check an STL for errors), then:

Error Fix Stop if
Duplicate or zero-area triangles Run standard cleanup on the STL Repair page (uploads the file). Details: duplicate triangles, zero-area triangles. Visible geometry disappears, or serious errors remain.
Flipped faces on a closed part Let cleanup correct them, then recheck. See flipped normals. The part is open, or it is unclear which side is outside.
Loose pieces Review them on STL Repair. All pieces start kept; "Keep largest part" suggests the biggest one. You cannot tell whether a piece is meant to be there.
Holes (open edges) Rebuild the missing surface in CAD or a mesh editor. See fixing holes. You do not know the shape of the missing surface.
Non-manifold edges or overlapping parts Fix the join in the CAD model. See fixing non-manifold STLs. An automatic merge would fill a hollow or a mating face.

Making a file smaller by reducing detail is a different task: see how to reduce STL file size.

The two InspectMesh repair actions

Piece review runs in your browser. It saves only the pieces you keep, unchanged. It does not fix duplicates or add missing faces. In our example, 20 triangles make up a 12-triangle cube and two small 4-triangle pyramids; "Keep largest part" suggests the cube, but being smaller does not prove the other pieces are junk.

Standard cleanup runs only when you press "Clean STL safely", and uploads the file. Its report lists removed duplicate or zero-area triangles, flipped faces it corrected, and anything it could not fix. It does not use your piece selection, and it cannot close a missing side.

Repair in PrusaSlicer or other tools

Prusa's article on corrupted 3D models says PrusaSlicer repairs models automatically "to a certain degree", and on Windows 10 offers "Fix by the Netfabb" from the right-click menu of the model or its warning symbol. It also lists Meshmixer and Microsoft 3D Builder as free repair tools. Prusa documentation checked 28 November 2026.

Check the repaired file

  1. Reopen the saved STL and note its triangle count, size and quality results. A volume that cannot be calculated is not zero.
  2. Look at the area you changed. To see how far the surface moved, compare old and new files in STL Compare. It samples the surface, so very small features can be missed.
  3. Slice it and check the affected layers, dimensions, openings and separate parts.

File size and triangle count alone do not show whether a repair is good: in our tests, a re-triangulated copy had different bytes and no measurable change, while a widened cube moved its surface by 4 mm. If a file will not import at all, start with STL file won't slice.
