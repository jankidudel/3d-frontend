If your STL imports about 25.4 times too small or too large, it was almost certainly designed in inches and opened as millimetres, or the other way round. A factor of 10 usually means centimetres. This happens because an STL file stores only numbers, not units, so every program has to guess.

Why STL files have no units

An STL is a list of triangle corner coordinates. A cube edge stored as 20 could mean 20 mm, 20 cm or 20 inches; the file does not say which. Most slicers assume millimetres. If the designer worked in inches, a 20-inch part arrives as a 20 mm part.

Match the size error to the cause

Stored number If it was meant as Real size Imported as mm, it is
20 Millimetres 20 mm Correct
20 Centimetres 200 mm 10 times too small
20 Inches 508 mm 25.4 times too small

A model that arrives 25.4 times too large is the reverse case: it was modelled in millimetres and a program read it as inches.

Confirm before you resize

A 25.4 ratio is a strong clue, not proof. Someone may have scaled the model on purpose. Check one dimension you know for certain before changing anything:

  1. Find a trusted size: a drawing, a product listing, a screw hole of known diameter, or ask the designer.
  2. Open the file in the STL dimensions checker and compare that feature under millimetres, centimetres and inches.
  3. Check a second dimension too. If both match the same unit, you have found the cause.

You can practise on the 20 mm example cube: its stored numbers stay the same under every unit choice, only the interpretation changes.

Fix it: reinterpret or resize

There are two different fixes, and it matters which one you choose:

  • The file is right, the program guessed wrong. Change the unit or import setting in the program that opened it. Resizing the file would just create a second error later.
  • The numbers really are in inches. Scale the model by 2540% (inches to mm) or 3.937% (mm to inches), save a new copy and keep the original.

In PrusaSlicer, you can type the target size into the Size fields of the object manipulation panel, or measure a known feature with the measurement tool and scale the object so that distance matches (PrusaSlicer 2.6 and later; Prusa documentation checked 28 November 2026). For the full step-by-step, see how to scale an STL; for the percentage maths, see STL scale factor explained.

Stop it happening again

STL can never carry its unit, but 3MF can. If you share models with other people, convert to 3MF once the size is correct so the unit travels with the file. Converting does not fix a wrong size by itself.
