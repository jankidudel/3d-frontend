An STL is watertight when its surface is fully closed: every triangle edge joins at least one other triangle, so there are no holes. To check, run the file through the STL Watertight Checker and look at the open-edge count. Zero open edges means the surface is closed. Any open edges mark a hole or gap you should inspect before slicing. Watertight is not the same as manifold or printable: a closed model can still have overlapping parts or walls that are too thin.

See it on two example files

The closed 20 mm cube has 12 triangles and no open edges. The open-face copy is missing two triangles (one side) and has 4 open edges. Opened as millimetres, the closed cube's volume is 8,000 mm³; the open copy has no volume, because an open surface does not enclose anything. Try both before reading the result for your own file.

What your result means

Result What it means Next check
Open edges above zero The surface has at least one hole or gap. Find the hole and compare it with the design; decide whether to fill it.
Zero open edges, one piece The surface is closed. Also check flipped faces, non-manifold edges, overlaps, size and the sliced layers.
Zero open edges, several pieces Each piece is closed, but the file holds several parts. Check which parts belong and whether any overlap; do not delete pieces just to lower the count.
File failed to load or check did not run You have no result, not a clean one. Export the file again and rerun the check.

An opening in the shape is not always a hole in the mesh. A thick-walled cup with an open top, or a block with a channel drilled through it, is still closed, because its walls wrap around the empty space. A single sheet with no thickness has open edges. Hidden inner surfaces or overlapping parts can remain even with zero open edges; the STL preflight runs those other checks.

If you have several kinds of errors, start with how to check an STL for errors.

Watertight versus manifold

Watertight means closed: every triangle edge has a neighbouring face, so the surface has no open boundary. Manifold is stricter. Each edge must also be shared by exactly two faces, so a mesh can be watertight yet non-manifold. Two closed cubes that touch along one edge have zero open edges, but that shared edge belongs to four faces.

Check Question it answers Tool
Watertight Does any edge belong to only one face? STL Watertight Checker
Manifold Does any edge belong to one face, or to more than two faces? STL Manifold Checker

Neither check finds crossing surfaces; see self-intersection versus non-manifold geometry. For the edge types themselves, read what non-manifold geometry is.

Recheck the file you will slice

  1. Keep the original and note where the holes are and how many open edges there were.
  2. Fill only holes whose intended shape you know; rebuild functional surfaces in CAD.
  3. Open the saved copy, run the watertight and manifold checks again, then check the size and the sliced layers around the repair.

Watertight is one property of a model. It does not tell you about wall thickness, supports, whether it fits your printer, or how the print will turn out.
