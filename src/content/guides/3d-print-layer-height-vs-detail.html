Compare a ramp example and inspect the actual sliced feature.' slug: 3d-print-layer-height-vs-detail eyebrow: Geometry and slicing heading: 'When does a smaller layer height improve print detail?' ---

Smaller layers can represent changes through height more finely, but they do not restore geometry missing from a coarse mesh or automatically make a narrow XY stroke printable. Identify whether the visible problem follows the layer direction, line width or source surface before changing the profile.

Identify the feature and its direction

Start with one named feature on a particular revision. Check its source shape and how it lies relative to the printer's horizontal bed plane. A smooth-looking mesh preview and a dense layer preview answer different questions; neither establishes the physical surface finish.

Choose the investigation from the observed feature
Observation Useful investigation Unjustified conclusion
Coarse steps on a shallow slope Layer schedule, local slope and orientation Every defect is caused by too few triangles
Narrow XY stroke omitted Actual material width, source geometry and perimeter paths Smaller layers must restore the stroke
Shallow raised or recessed Z detail missing Relief, actual slice planes, first-layer and adaptive schedule Relief divided by nominal layer height guarantees paths
Polygonal curve already visible in the mesh Source tessellation and the exact exported derivative A finer layer profile recreates the source CAD curve
Poor support-facing surface Orientation and actual support interface Finer layers alone establish a finished surface

Work through a shallow ramp

This original hypothetical geometry is an ideal planar ramp z = 0.1x over X=0..30 mm, rising from Z=0 to Z=3 mm. Its angle relative to the horizontal bed plane is atan(0.1) ≈ 5.71 degrees. It is an upward surface, not an overhang threshold.

For successive equally spaced horizontal levels with vertical increment h, the ramp equation gives delta x = h / 0.1. The table is geometric sampling, not a measured print.

These spacings are not recommended settings, measured terrace widths, surface roughness, cusp-height bounds or a finish guarantee. Deposition shape, actual line width, layer-plane convention and slicer behaviour affect the appearance. A curved surface changes slope, so it does not have one constant spacing from this equation.

Keep XY width, Z sampling and source fidelity separate

Nozzle diameter, actual line width and layer height are separate values. Reducing the vertical increment does not widen a narrow stroke. Increasing the source triangle count does not change the nominal layer schedule. Prusa's layers and perimeters documentation distinguishes vertical layer resolution from XY detail and describes perimeter controls; its profile guidance is not a universal minimum-detail rule.

For dimensional planning, use the nozzle and wall planner to compare an entered width and approximate equal-width count. Its layer/nozzle ratio is a bounded starting screen, not a print-quality certificate. If the source curve is already faceted, return to chord deviation and tessellation; smaller layers cannot restore the omitted CAD curve.

Compare orientation with the other requirements

Reorienting a slope changes its relation to horizontal layers. It also changes bed contact, support access, critical faces and potentially the load direction. Use the orientation comparison to rank those requirements before accepting a surface improvement. A mesh view cannot certify the resulting finish or strength.

Review variable layers and effective settings

Prusa's variable layer height reference documents automatic and manual regional schedules. This can target a region rather than apply one increment everywhere. Review the generated schedule, first layer and effective object/profile overrides. A named profile or quality slider does not establish that only layer height changed, or supply a fixed time-saving ratio. No current menu walkthrough or new slicer run is claimed here.

Inspect actual paths where the feature matters

The retained T3 lettering evidence gives a specific Z-detail comparison: the 0.10 mm relief has no deposition above the base under the coarse 0.20 mm schedule, while the finer 0.10 mm schedule records glyph paths at Z=2.1. Both nominal layer height and first-layer height changed. This is an identified software observation, not an isolated one-variable experiment or physical test. The lettering guide retains the detailed conditions and counts.

Compare the source feature with the effective schedule and the exact exported output, including the first affected layers and extrusion categories. Travel height and a selected preview range can mislead. Dividing nominal feature height by nominal layer height does not give an exact generated-layer count; first layers, adaptive schedules and slice placement matter.

Compare the complete job before choosing

At entered width and speed, changing height changes approximate requested throughput; use the volumetric-speed explanation for that arithmetic and applicable capacity evidence. It does not predict surface improvement or elapsed time. Halving layer height does not establish exactly twice the duration, half the strength, smaller XY error or a particular roughness.

Record actual generated duration and complete per-material consumption when supplied. Keep unknowns unknown. Reuse those reviewed inputs in production costing, rather than carrying an old job estimate into a changed schedule.

  1. Record the named feature, revision, view and measurement direction.
  2. Keep the effective width, first layer and full height schedule.
  3. Make one justified change and retain any other effective overrides.
  4. Identify the exact exported output and compare the affected paths.
  5. Record supplied duration and consumption; leave the physical result unresolved until relevant testing.
