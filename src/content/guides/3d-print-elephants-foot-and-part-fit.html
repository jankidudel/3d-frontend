If a part fits above the bed-facing edge but binds at its base, first localise the error. An all-height size correction can spoil the portion that already measures correctly. This guide diagnoses base interference; calibration owns the wider setup sequence.

Measure by height before selecting a control

Check how the cooled base sits before interpreting a lower caliper reading. A wide base that seats and a base that lifts at one corner or rocks need different checks. Record the support points and investigate when the base lifted if the seating changes.

Position Designed width Hypothetical reading Interpretation to investigate
Base 20.00 mm 20.30 mm Local interference at bed-facing edge
Middle 20.00 mm 20.00 mm No adjustment shown here
Upper 20.00 mm 20.01 mm Assess method and repeated spread

Keep base, middle and upper readings in separate sets with the same datum and direction. An average across those heights would conceal the symptom. Remove loose debris according to the agreed finishing procedure, distinguish an intentional chamfer or brim from the part, and inspect the source section before assuming the flare was created during printing. If all heights disagree similarly, use whole-part diagnosis instead.

Which operation changes which region?

Operation Intended scope Check before using it
First-layer compensation Bed-facing layer contours Thin features, holes and brim contact in the actual profile
Global XY scaling XY dimensions throughout the part Dimensions above the base and all mating features
Local source feature edit Selected CAD geometry Remaining walls, lead-in and interface requirements
Slicer feature offset The contours documented by that control Sign and radius/diameter convention; do not substitute another slicer’s value

Prusa documents Elephant foot compensation under Print settings - Advanced in Advanced or Expert mode, with adaptive thin-line handling and possible effects on brim connection and thin-feature previews (checked 2 November 2026; the page is categorised under PrusaSlicer 2.9 Legacy). Verify your installed version and selected profile. No numerical setting is prescribed here; a preview is not the final squished footprint.

In a print-in-place joint, higher regions may remain separated while the bed-facing moving interface binds. Inspect that location, including any brim contact, before changing every wall or globally scaling. A chamfer or first-layer control has a local role; neither proves release or clears interference elsewhere in the travel.

Conservative confirmation sequence

  1. Save the source, slicer version/profile, existing compensation and build-surface condition. Identify whether the symptom is already modelled.
  2. Follow the printer manufacturer’s first-layer and surface procedure. Review the actual nozzle offset and temperature configuration; neither has a universal corrective value.
  3. Use a representative coupon containing the base interface and nearby small features. Record height-specific measurements and how the real mating part contacts it.
  4. Change one justified variable, preserve its before/after value and compare another coupon under comparable conditions.
  5. Check adhesion, brim separation, small features and the above-base fit. Stop if the change compromises any required condition.
  6. Record the proposed adjustment and outcome in the fit worksheet; confirm the whole assembly before acceptance.

When restriction persists along a bore away from the base, consult local hole compensation or orientation diagnosis. Adding a clearance value cannot identify or repair an unstable first layer.
