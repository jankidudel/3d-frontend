A non-manifold warning in a 3MF has two possible sources: a broken mesh inside one object (for example a duplicated triangle), or perfectly healthy objects placed so they overlap or touch. Find out which it is before editing. Fixing the wrong one can break other copies of the same object, or delete a part you need.

Mesh problem or placement problem?

A 3MF can store one object once and place it several times. Compare two example files:

  • Two placed cubes: one cube object placed twice. Our checker reports two pieces and no mesh problems (saved report). Do not delete the second cube just to get one piece; it is meant to be there.
  • Cube with a repeated face: one triangle is stored twice inside the object, giving one duplicate and three non-manifold edges (saved report). This needs a fix inside the object, not removal of a placement.

Both reports are from 24 October 2026; file hashes and how to reproduce them are in the test details. The 3MF Manifold Checker gives totals for the whole build, not a per-object diagnosis, so use the program that made the file to see which object is affected.

What to do in each case

What you find Question Action
One broken object used several times Which copies use it? Fix the object once; check every copy afterwards.
Healthy objects that overlap when placed Is the overlap intended? Move or merge them in the source program. The edge check does not detect overlaps.
Separate closed parts, no edge problems Are the number and spacing right? Keep them and check the plate layout.
Open or non-manifold edges reported Which surface should be there? Find the area, then remove the extra face or rebuild the missing one.
The file uses features InspectMesh does not read Did the check actually run? Keep the original and use the program that made it.

What the check does and does not cover

The server check looks at each placed object on its own. It counts an edge with one face as a hole and an edge with more than two faces as non-manifold, and it flags neighbouring faces that point opposite ways. It skips zero-area faces, but keeps duplicate faces in the count. Pieces that share a corner count as connected, so two parts touching at one point may appear as one.

It does not merge nearby points, test whether surfaces cross, or prove that every corner is manifold. The browser check combines all objects first, so it can group overlapping placements differently. Note which check you used.

After fixing

Compare objects, positions and sizes with the original, run the check again and look at the sliced layers. For holes, see which part of a 3MF has holes. For removing extra faces, try 3MF Repair. For other cases, see how to repair a 3MF. Keep intended parts separate; fewer pieces is not a goal in itself.
