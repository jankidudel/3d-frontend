Hollowing removes material from inside a model while keeping an outer shell. It is common for large resin prints and can also be useful for some FDM models.

The goal is to save material and reduce weight without making the shell too weak to print or use.

Start with a clean model

Before hollowing, check the STL with the STL Quality Checker. Hollowing works best when the model is a closed, consistent solid.

Use the STL Watertight Checker to look for open edges. A model with holes or non-manifold geometry can confuse the process because the software may not be able to tell what is inside the object.

If the file has simple repairable defects, try the STL Repair Tool first, then validate it again.

Choose a suitable shell thickness

The right shell thickness depends on the printing method and the model’s purpose.

For FDM printing, walls need to work with your nozzle width, perimeter count and infill strategy. In many cases, configuring perimeters and infill in the slicer is more practical than hollowing the mesh itself.

For resin printing, hollowing is often more important because a fully solid large model can use substantial resin and create high peel forces. The shell still needs enough thickness to survive handling and curing.

Add drain holes for resin prints

A hollow resin model needs a way for uncured resin to escape. Add drain holes in low, hidden areas that will be reachable during washing and curing.

Without drainage, resin can remain trapped inside the model. This can create a messy print, make cleaning difficult and cause later problems as trapped resin expands or leaks.

Plan the print orientation before placing holes. The lowest points during printing are often the most useful drainage locations.

Check the result before printing

After hollowing, inspect the model in your slicer and review the layer preview. Confirm that the shell remains thick enough, holes are in sensible positions and supports do not block drainage.

Use the STL Dimensions Checker if you need to confirm the overall size after editing. Hollowing should not change the outside dimensions, but checking avoids accidental scaling mistakes.

Hollowing is a design and print-preparation decision, not simply a file-size trick. A clean mesh, suitable wall thickness and a proper drainage plan matter more than removing the maximum possible material.
