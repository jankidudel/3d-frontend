To scale an STL, check its current size, choose the one dimension you want to hit, and apply a uniform scale to a copy of the file. Then reopen the copy and check all three dimensions before slicing. Watch out for holes and mounting points: they change size too.

Before you start: is the size really wrong?

If the model is about 25.4 or 10 times off, it is probably a unit mix-up, not a sizing choice. Fix the unit first. Open the file in the dimensions checker or STL viewer and compare one dimension you know.

Scale with InspectMesh

  1. Keep the original file. Download the 40 x 20 x 10 mm example block if you want to practise.
  2. Open STL Scale. Either enter a percentage (150) or choose a target dimension (Width = 60 mm). Width, depth and height are the X, Y and Z sizes.
  3. Keep scaling uniform, check the factor and the new dimensions, then download the copy under a new name.
  4. Reopen the downloaded copy. The example should now measure 60 x 30 x 15 mm.

For the percentage maths, including ready-made values for unit fixes, see STL scale factor explained.

Scale in PrusaSlicer

PrusaSlicer's object manipulation panel has Scale factor and Size fields: type a percentage, or type the target size in millimetres. The orange reset arrow returns the scale to 100%. Its measurement tool (PrusaSlicer 2.6 and later) can also scale an object uniformly so that a distance you measured matches the length you need. Prusa documentation checked 28 November 2026.

Watch out for holes and mounting points

Uniform scaling changes every length by the same factor. At 90%:

Example arithmetic only, not fastener recommendations.
Feature Before After 90%
Mounting hole spacing 32.0 mm 28.8 mm
Screw hole 4.50 mm 4.05 mm
Screw head recess 7.20 mm 6.48 mm

If a part must still fit existing screws or another part, scaling the whole model will break that fit. Change the overall size in CAD and keep the screw holes and head recesses at their original size. InspectMesh only scales the whole model.

Check the result

  • Reopen the saved copy and compare all three dimensions with what you expected. Our 150% example output measured 60 x 30 x 15 mm with 12 triangles and 27,000 mm³ volume when reopened (recorded result). That is a software check, not a print test.
  • Slice it with your real profile and check that it still fits the bed with brim and supports. For round beds, see round bed fit.
  • For parts that must fit together, print a test and measure it. The tolerance calculator helps you record the readings.

Scaling does not repair the mesh and does not add a unit to the STL file.
