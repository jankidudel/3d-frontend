Confirm the intended unit and current size, choose one target dimension, then resize a separate STL copy. Reopen the downloaded file and check all three dimensions before you slice it. Do not scale an entire functional part when a fixed hole or mating feature must stay unchanged.

Establish the source size

Preserve the supplied file and revision. Use the dimensions checker or local viewer to compare a known source dimension under the intended unit assumption. If that evidence is missing, resolve the unit ambiguity before changing coordinates.

If the source coordinates already match the known dimension, correct a wrong receiving unit assumption first. If the intended physical size really changes, resize a copy; scaling does not repair topology.

Choose a target and uniform mode

For the owned asymmetric control, X/Y/Z are 40 × 20 × 10 mm under its designed millimetre convention. Target X = 60 mm gives one factor of 1.5, or a final 150%. Expected Y and Z become 30 and 15 mm. The arithmetic reference explains percentage changes separately.

Every length changes together. If mounting centres, a hardware passage or head seat must remain fixed, edit the relevant local features in source CAD. InspectMesh performs uniform scale; it does not selectively enlarge bores or restore hardware interfaces after scaling.

Resize a separate copy

  1. Download the original 40 × 20 × 10 control and retain it.
  2. Open STL Scale. Choose Percentage = 150, or Target dimension = Width with a 60 mm target. The tool labels X/Y/Z spans as width/depth/height.
  3. Use uniform scaling. Inspect the factor and resulting dimensions, then download a separately named STL.
  4. Do not overwrite the original. Record the unit convention expected by the receiving application. STL still has no unit declaration.

Reopen and compare

Open the exact downloaded bytes. Compare 60 × 30 × 15 mm with the expected spans and check important local features. The retained 1.5× output was actually serialized and reopened using the browser algorithms locally; its 12 triangles and enclosed volume of 27,000 mm³ are recorded in the dated observation. This is software evidence, not a slicer import or physical test.

The example uses a 0.00001 mm comparison tolerance for Float32 coordinate storage. Display decimals do not establish manufacturing accuracy. Check actual slicer layers, usable bed space, supports and brim under the intended profile before accepting the change.

Scaling also changes holes, walls and clearances. An illustrative 5 mm hole becomes 7.5 mm at 1.5×. If that interface must stay fixed, return to CAD; use the fit worksheet for physical readings rather than interpreting a mesh span as acceptance.

A circular-envelope scale value solves the stated XY-corner and independent Z inequalities only. With physical per-side allowance a, scale s applies to the body spans, giving (sW+2a)^2+(sH+2a)^2 <= (D-2e)^2; it does not scale the brim reservation. Review the shape decision before shrinking an irregular outline merely because empty envelope corners failed. The comparison leaves the source untouched; applying scale in the tool changes every source dimension in the exported copy.
