A small path can lie outside a print bed because its location, the coordinate origin and travel moves matter as well as its width. Compare explicit minimum and maximum coordinates in a reviewed frame. An observed out-of-bounds path asks a machine-specific question; it does not establish a collision.

Ten millimetres wide, outside the entered frame

In the analytical shifted-location control, a travel reaches X=230 and the following positive-extrusion path ends at X=240. Its extrusion width is only 10 mm. Against explicitly entered X=0..220, that entire extrusion segment is outside. Comparing 10 with 220 would miss the location problem. The initial model state is logical XYZ=0, millimetres and absolute XYZ/E after the mode commands. This is hypothetical geometry, not a manufacturer's usable area.

Separate extrusion from travel

The second control extrudes from X=10..110, Y=20..120 and Z=0.2..20, then travels to X=230. In a reviewed X/Y=0..220 and Z=0..200 frame, positive extrusion is inside while all parsed motion extends outside. Both observations belong in the record. Prime/purge paths may also extrude outside the intended object envelope, and travel includes start/end moves and Z hops.

Enter a frame deliberately

  1. Open the file in the existing viewer and read coverage before geometry.
  2. Enter reviewed minima and maxima for X/Y/Z. A dimensions-only saved printer model profile does not establish a path origin or verified machine region.
  3. Inspect both scopes and any unsupported effects.
  4. Keep the review record with its assumptions, then verify placement and machine-specific moves in the native slicer.

G92 can set logical position without an ordinary move; firmware documentation is needed to relate logical values to physical position. InspectMesh marks XYZ resets as incomplete machine-space coverage. G2/G3 arcs are omitted from its linear extents.
