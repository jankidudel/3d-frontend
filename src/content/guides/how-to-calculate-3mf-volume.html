Resolve the intended 3MF build, establish its physical unit and check whether the selected method can report an enclosed-volume value. Repeated placements and transforms affect the geometry, but the current InspectMesh volume method can withhold a result for multiple components. Unavailable does not mean zero.

Choose the build scope and unit

A stored resource is not a placed instance. Identify the build that should be measured and resolve its supported placements before comparing values. Declared units and supported transforms affect physical geometry; unused resources do not automatically contribute. Use the local viewer to inspect expected inventory and trace a missing placement before requesting a measurement.

Compare volumes only after interpreting both units and scope. Divide mm³ by 1,000 to obtain cm³. A plain number copied from another method is not comparable without its unit and the chosen surfaces.

Read the method's availability state

Pressing Calculate 3MF volume in the volume calculator uploads the selected file for server processing. Supported placements resolve before its screen. The current report builder requires valid geometry, one connected component, no open or over-shared edges and consistent orientation before supplying volume. This method uses shared-vertex connectivity; the local collection screen has its own topology policy. Neither method performs a Boolean union by adding shell magnitudes.

State Interpretation Next step
Available supported value The method supplied a value under its implemented screens Confirm physical unit, intended geometry and remaining unchecked conditions
Unavailable with a completed report A solid/scope screen withheld the value; this is not zero Inspect topology and component scope; do not calculate mass from a missing value
Processing error or absent report No completed volume measurement from this attempt Resolve the stated file/processing issue before using any estimate

One cube and two placed cubes

These owned controls separate analytical geometry from actual software output. Retained reports were produced by the local .NET ProcessorApplication code path used by the server, not by a deployed endpoint or an external slicer. Input hashes and the capture method/date are preserved in the evidence provenance; the current local rerun is documented in the 27 October processor record.

Control / scope Analytical expectation Actual processor result
One placed 20 mm cube 8,000 mm³ = 8 cm³ 12 triangles; one component; approximately 8,000 mm³
Two disjoint placed 20 mm cubes 16,000 mm³ = 16 cm³, assuming separate non-overlapping material regions 24 triangles; two components; completed report with no listed issues, but volume null/unavailable

Download the one-placement and two-placement packages and retained one-item report / two-item report. The two-item arithmetic is not an observed endpoint total. A successful parse and empty finding list do not override the volume availability rule.

For separate closed, disjoint bodies, a CAD or analytical sum needs its own assumptions. Intersecting copies double-count overlapping regions if added independently. Nested shells may have ambiguous solid meaning. Return to suitable source solid operations when the intended material region is unclear.

Compare a derivative with the same scope

An entire-build STL can contain both placements, while a selected-item export contains only one. Preserve resolved coordinates, interpret the STL as millimetres and compare named references. The delivery-scope guide explains this decision; the 3MF scale guide owns transform arithmetic. Comparing one exported cube with a two-cube build is a scope change, not evidence of a faulty volume conversion.

Use geometry volume for geometry, sliced totals for consumption

An available value can support geometric comparison or optional solid-mass arithmetic using a stated density. No mass follows from an unavailable value. Use the solid-mass versus sliced-use guide for density assumptions. Walls, infill, supports, purge and the actual arrangement determine the production material total; use the final slicer output for that job.

Representation basis reviewed 27 October 2026: 3MF Core Specification 1.4.0. Processor availability is an InspectMesh method policy, not a universal rule for all 3MF software or proof of physical printability.
