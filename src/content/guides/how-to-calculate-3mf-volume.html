To calculate the volume of a 3MF, upload it to the 3MF Volume Calculator: it reads the file's unit and reports the volume of the closed shape in mm³ (divide by 1,000 for cm³). A 20 mm cube is 8,000 mm³ or 8 cm³. If the result is blank, the build is open, damaged or made of several separate parts. Blank means "could not be calculated", not zero.

Before you measure: which objects and which unit?

A 3MF can store an object without placing it, or place the same object several times. Only placed objects count. Open the file in the 3MF viewer to see what is actually on the build plate, and if something is missing see missing objects after import.

Always compare volumes in the same unit and for the same objects. A number copied from another program means little without its unit and what it measured.

When you get a volume, and when you don't

The calculator uploads the file for server processing. It only reports a volume when the build is valid, forms one connected part, has no holes or non-manifold edges, and all faces point the same way. It does not merge overlapping parts.

Result What it means What to do
A volume is shown The build passed all the checks above Check the unit and that the right objects were measured
Report completes, volume blank One of the checks failed; it is not zero Look for holes, separate parts or flipped faces; do not calculate weight from a blank value
Error or no report The file could not be measured Fix the file or processing problem first

Example: one cube vs two cubes

Example file Expected by maths What InspectMesh reports
One 20 mm cube 8,000 mm³ = 8 cm³ 12 triangles; one part; about 8,000 mm³
Two separate 20 mm cubes 16,000 mm³ = 16 cm³ if they don't overlap 24 triangles; two parts; no problems listed, but volume blank

Try it yourself: download the one-cube and two-cube files and our saved one-cube report and two-cube report. Test details are in the evidence record and the 27 October rerun. These ran on InspectMesh's own processing code, not a live server or a slicer.

For several separate parts, you can add their volumes yourself only if they do not overlap: overlapping copies would be counted twice. If parts are nested or overlap, merge them in your CAD program first.

Comparing with an exported STL

An STL exported from the whole build contains every placed object; one exported from a single object contains only that one. Comparing a one-cube STL with a two-cube 3MF will of course give different volumes. See combined or separate STL parts, and for resizing see how to scale a 3MF.

Volume is not filament use

Volume tells you the size of the solid shape. With a material density you can turn it into a solid weight (see estimating weight from a 3MF), but a real print uses walls, infill, supports and purge, so it usually needs much less or more than that. For the filament a job will actually use, read the total from your slicer.

Based on the 3MF Core Specification 1.4.0, reviewed 27 October 2026. The rule that volume is left blank for separate parts is InspectMesh's own choice, not a rule of the 3MF format.
