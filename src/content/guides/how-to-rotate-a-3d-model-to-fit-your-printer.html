A model that is too tall or too wide in its current orientation may fit when its dimensions are placed along different printer axes. - question: Does rotating a model in a slicer change its size? answer: No. Rotation changes which printer axis each model dimension uses, but it does not scale the model. - question: Will every rotation be checked automatically? answer: InspectMesh checks practical 90-degree orientations. An unusual angled rotation may fit differently, but it can also affect support needs, bed contact and print quality. ---

Rotation changes which source dimension uses printer X, Y or Z without changing model size. Test explicit axis assignments before reducing a functional part. Keep the current orientation result as the baseline, then compare practical right-angle alternatives.

Map source axes to printer axes

InspectMesh's model Width/Height/Depth convention is X/Y/Z. Printer inputs now name those axes explicitly: X and Y span the bed; Z is the build height. Confirm legacy saved values instead of assuming Height meant vertical Z. A preset labelled 220 x 220 x 250 means X=220, Y=220, Z=250.

Use one worked axis-permutation example

For a hypothetical source X=230, Y=160, Z=90 mm and rectangular region X=180, Y=180, Z=240 mm, the current orientation exceeds X. Mapping source Z to printer X, source Y to printer Y and source X to printer Z gives 90 x 160 x 230 mm: contained under those nominal dimensions. Mapping source Y to X, source X to Y and source Z to Z gives 160 x 230 x 90 mm, which exceeds Y. Comparing only the largest model span with the largest printer dimension would miss that distinction.

Choose the correct shape screen

The fit checker tests distinct right-angle permutations in automatic mode, or the current assignment only. For a circle it checks a centred full XY rectangle plus a separate Z limit. A rigid centred rectangle keeps the same corner radius when turned in its own plane: swapping X/Y cannot repair an excessive diagonal. Choosing a different build axis changes XY and Z together. See the round-bed interpretation before treating an empty envelope corner as proof the actual outline must shrink.

The orientation planner keeps six signed build directions and compares downward-facing area and estimated coplanar contact alongside fit. Those measures answer different questions. A contained candidate can increase support demand, worsen a critical surface, reduce stable contact or change load direction across layers. Exact exclusions and arbitrary-angle rotations still need the native profile.

Apply and verify the candidate

  1. Confirm STL units or resolved 3MF build scope and units. Several placed objects can contribute to one total envelope.
  2. Record the source-to-printer axis assignment and enter the documented usable shape and dimensions.
  3. Apply the rotation in the slicer or modelling application; this comparison screen does not rotate or export your file.
  4. Recheck resulting X/Y/Z and source position. For an assembly, preserve the intended shared origin and relative placement.
  5. Generate supports and adhesion structures, then review the additional process-space footprint, complete layers and native machine clearances.
  6. Save the native project/profile so the chosen rotation remains reproducible.

Decide whether scaling or splitting is appropriate

If practical orientations still fail, compare a deliberate split with a design revision before shrinking fixed hardware interfaces. An envelope scale value is only a bound under its shape, Z and allowance inputs. The Dimensions/Orientation comparison does not apply scaling. The separate STL Scale Tool exports a uniformly resized copy; every hole, wall and mating feature changes too. Preserve the original and reopen the derivative to check dimensions before slicing.

For arbitrary angled placement, recompute the real geometry bounds after rotation. Right-angle candidates are not an exhaustive search or a print guarantee. A mathematically contained arrangement still needs support, surface, strength and physical review.
