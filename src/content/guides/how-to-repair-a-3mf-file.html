To repair a 3MF, first work out what is broken: the file itself, the objects and their positions, or a mesh inside an object. InspectMesh's 3MF Repair removes extra and zero-area triangles in your browser and keeps everything else. It cannot fill holes or flip faces, so those need your CAD or slicer. Keep the original and check the repaired file in the program you print from.

Match the problem to the fix

Problem What to do
The file will not open or parts of it cannot be read Export it again from the program that made it. Triangle cleanup cannot rebuild a damaged file.
An object is missing or in the wrong place Check the objects, positions and scale against the original project before removing anything.
Duplicate, zero-area or broken triangles Use 3MF Repair and review what it plans to remove. A file that cannot be read at all will not reach this step.
Holes, bad joins, flipped faces or overlapping parts Fix them in the original model or a mesh editor. Removing triangles cannot rebuild a surface.
The model looks fine but the slicer drops a feature Compare the sliced layers and settings in your slicer.

Using 3MF Repair

Choose the original file in 3MF Repair and review the triangles it proposes to remove. It runs in your browser, saves a separate file and does not upload anything. If it proposes nothing, there is nothing it can fix; that does not mean the file has no other problems.

It finds triangles that repeat the same three corners within one object, in any order, and triangles with almost no area. It does not merge nearby points. The file must open correctly first; if it cannot, export it again from the source program.

One fix can change several copies

A 3MF can store an object once and place it several times. Removing a triangle from that object changes every copy placed in the build. That is different from deleting one placed copy. After saving, check you still have the right number of objects in the right places.

The 3MF specification separates stored objects from the items placed for printing. That defines the format; it does not mean every program supports every 3MF feature. The repair keeps coordinates and the rest of the file and removes only the selected triangles. The new file will not be byte-for-byte identical, because the ZIP is rebuilt.

Test file for size and position

To check that a workflow keeps size and position right, use our one-inch cube moved two inches along X. Read correctly, it is a 25.4 mm cube between 50.8 and 76.2 mm on X. Compare those numbers before and after any repair. See how to convert 3MF to STL for our measured conversion results. A clean mesh does not prove the slicer kept the project settings.

Check the repaired file

  • Reopen the downloaded file and confirm it still opens.
  • Compare units, objects, positions and overall size with the original.
  • Check how many triangles were actually removed and what problems remain.
  • Run 3MF preflight on the saved copy (in your browser). Use the server checks too if you are happy to upload the model.
  • Open it in your slicer and check the affected layers, materials and settings.

When to go back to the original model

Stop if fixing it means guessing a functional surface, identifying an unknown part, or choosing which overlapping areas to keep. Go back to the design or the program that made the file.
