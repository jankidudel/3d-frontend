First decide what failed: opening the package, resolving its placed items, or interpreting its mesh. InspectMesh's local 3MF Repair removes supported defective triangle records; it does not reconstruct a missing surface or correct winding. Keep the original and verify the saved package in the application that will use it.

Identify the layer before selecting a repair

Observed problem Appropriate next action
Archive, model relationship or required resource cannot be read Re-export from the producing application. Do not rebuild unknown references through triangle cleanup.
Required item is absent or unexpectedly placed Inspect build references, transforms and the original project before removing geometry.
Duplicate, degenerate or supported invalid-index triangle records Review the local removal plan and apply only an understood supported change. Packages that fail resolution cannot reach this plan.
Open surface, ambiguous join, winding problem or crossing solids Inspect the source model or a suitable editor. Local triangle removal is not a reconstruction operation.
Geometry is plausible but the slicer loses a required feature Compare the affected layers, profile and project support in the producing/receiving applications.

Use local cleanup for a supported triangle change

Choose the original package in 3MF Repair and review its proposed removals. The supported operation runs in your browser and creates a separate package. It does not need the server quality-check action. An empty removal plan means no selected supported operation is available; it does not certify that the file is free of every mesh problem.

The removal plan identifies repeated vertex-index triples within a mesh, ignoring their order, and near-zero-area triangles under its relative tolerance. It does not weld coincident vertices. The package must first pass the local geometry resolver; invalid indexes that prevent resolution require a source export.

A shared resource can affect several placements

A triangle edit belongs to a stored mesh resource. If several placed items reference that resource, the edited mesh can appear in each placement. Removing one redundant triangle from the resource is different from deleting a build item. Confirm the required quantity and arrangement after saving.

The 3MF Core specification distinguishes resources from build items selected for manufacture. This defines the format, not a guarantee that this tool or a receiving application supports every extension. The repair keeps coordinates and surrounding XML text while removing selected triangle elements; decompressed payloads of unrelated ZIP parts are copied. A regenerated ZIP is not byte-identical to the source.

Geometry and coordinate control, not a repair observation

To test unit and placement interpretation separately from repair, download the generated one-inch cube translated two inches on X. The conversion control resolves it to a 25.4 mm cube at X = 50.8 to 76.2 mm. Compare the before/after dimensions and placement when validating any repair workflow; a successful mesh cleanup does not prove a receiving app retained project settings. See the measured 3MF-to-STL export workflow for the actual reopened conversion outputs.

Compare the saved package with the original

  • Reopen the exact downloaded bytes and confirm the package still resolves.
  • Compare source units, required resource references, placed items, transforms and build bounds.
  • Review actual removal counts and remaining findings. Do not assume every enabled operation was applied.
  • Run local preflight on the saved copy; choose server analysis separately if appropriate for the model's privacy requirements.
  • Open the result in the target slicer and inspect affected layers, material assignments and relevant project settings.

Return to the source when the intended geometry is unknown

Stop if the correction requires inventing a functional surface, identifying an unknown part, or guessing which overlapping regions should remain. Return to the source design or producing application. Keeping a package entry does not establish that another application will interpret it as intended.
