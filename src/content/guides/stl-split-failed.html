Diagnose the Cut Before Retrying ---

A failed STL split can come from the source mesh, the selected plane, an unsupported cut contour or a processing problem. Read the actual error first. Change one relevant condition and verify the saved outputs; repeating the same cut or applying unrelated repair does not identify the cause.

Find the stage that failed

Observation First check Relevant next action
File cannot be read locally Non-empty ASCII or binary STL, .stl name and 25 MiB limit Try the known cube below; resolve parsing before geometry diagnosis.
Submission or job fails without a geometry finding Created, upload, processing or failed status and the displayed error Preserve file, axis and percentage. Retry once when appropriate; do not invent a mesh cause for a timeout.
Input is rejected for mesh condition Open edges, over-shared edges, invalid coordinates, duplicate or degenerate triangles and winding Review the source in the relevant checker; correct only an understood problem.
Plane does not produce a usable division Displayed source-coordinate plane against bounds and material Choose an interior plane that genuinely crosses material and leaves geometry on both sides.
Cap or contour is unsupported The section shape and actual split error Inspect a nearby plane or return to CAD. A different plane is not guaranteed to work.
Job succeeds but one output is unusable Both downloads, bounds, closure and intended features Reopen both exports. Job completion is not an assembly-ready certificate.

The service currently distinguishes a split geometry rejection from a general processing failure, but it does not expose a separate code for every row. Preserve the real message. A generic processing failure or interrupted status poll does not prove that the mesh or plane is at fault.

The current splitter rejects these nested contours instead of filling across the passage. This is an algorithm boundary, not an open-mesh diagnosis.

Moving a plane can avoid a vertex, edge or coincident feature, but it changes the seam and retained geometry. For example, moving a proposed plane from Z=10 to Z=9.8 shifts the seam by 0.2 source units; save the Z=10 setting for comparison. It does not remove the tube's nested-contour condition, and a nearby plane is not a promise of acceptance.

What not to change blindly

Global scaling changes outside dimensions, holes, wall material and assembly interfaces. It is not a neutral response to a contour rejection. Use the scaling workflow only when size is the intended change.

Removing disconnected pieces can delete intentional parts, locating features or text. Use the component interpretation guide and retain every piece until its purpose is understood.

Filling holes may close an intended channel, drain, vent or socket. A cleaner issue count does not establish design intent. Follow the hole diagnosis and compare the result with the source design.

When to return to the source model

Use source CAD or a suitable native-mesh workflow when the seam contains complex openings, when interfaces or load paths are critical, when connectors must be designed, or when the relationship between solids is ambiguous. InspectMesh provides conservative axis-aligned planar cutting; it does not run a general Boolean union, repair source intent or design a joint.

Verify the downloaded pair

  1. Open both files again rather than inspecting only one download.
  2. Name the files with side, axis and model revision.
  3. Keep the physical unit assumption explicit because STL stores no unit.
  4. Compare bounds, seam coordinate and retained features with the intended cut.
  5. Check every required closed region; two exports need not mean exactly two connected objects.
  6. Confirm an intended opening remains open.
  7. Review final placement, supports and toolpaths in the target slicer.

If the two exports need a joining feature, continue with the alignment-pin planning and coupon workflow.
