A 3MF can carry model geometry and build structure, and some applications also use it to save a slicer project. Open it in a supported local viewer to inspect geometry or in the producing/receiving slicer to review project settings. Successful geometry display does not establish that the project was preserved.

Choose the opening task and processing boundary

The 3MF Viewer resolves supported geometry locally. Separate quality, dimensions and volume server actions have their own explicit upload notices. Optional issue-location analysis in the viewer also uploads only when deliberately requested. A local preview does not grant permission for those actions or verify the package's printer profile.

Open the two-placement control locally

  1. Keep the original package and identify the expected source revision. Download the two-placed-cubes control.
  2. Choose it in 3MF Viewer, or use its explicit example loader. The control declares millimetres, reuses resource 1 and has two top-level build items.
  3. Read the all-build bounds: X=0..60, Y/Z=0..20 mm. The empty gap contributes to bounds, not material.
  4. Select build-2 with the placed-item button, choose Isolate selected, then Frame selected. Its X interval is 40..60 mm and its span remains 20 mm.
  5. Choose Show all and compare the expected inventory. Nested component geometry remains within its top-level selection; a shell count is a different concept.

The local resolver and saved-byte export check on 27 October 2026 verify these references in the receiving evidence record. That execution is separate from testing an external slicer or physically printing either cube. Record what the actual receiver displays before accepting the handoff.

If the package cannot be opened

Preserve the failure message and original bytes. A 3MF is a structured package: an incomplete ZIP, malformed XML, missing resource/model relationship or unsupported required semantics can stop resolution before a mesh finding exists. Try the producing application and request a supported export when necessary. Another server checker is not a guaranteed bypass for unsupported semantics or missing resources.

A renamed mesh is not a valid 3MF package. Compare the received size and revision with the sender. If the known control also fails, investigate the opener's compatibility, resource limits and error before modifying the user model.

If the receiver needs geometry-only STL, choose whole-build or single-placement scope deliberately. Vertex coordinates can retain the resolved locations, but the STL lacks separate placement records and a unit declaration. Keep the original 3MF for project revisions and inspect final layers and profile in the intended slicer.
