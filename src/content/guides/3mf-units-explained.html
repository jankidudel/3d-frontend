Yes. Unlike STL, a 3MF file states which unit its coordinates use, and the 3MF Core specification says millimetres are assumed when the file does not say. That is why a 3MF usually opens at the right size. When it does not, the cause is normally a scale or placement saved in the project, or the program you exported from.

Why a 3MF can still look the wrong size

A 3MF holds more than one set of numbers. The size you see depends on all of them together:

What is stored What changing it does
The unit (for example millimetre or inch) Changes what the same coordinate numbers mean
The mesh coordinates Can be rewritten for a new unit while keeping the real size the same
A scale saved on a placed object Makes that object bigger or smaller in the build
The program's display unit Changes only how sizes are shown on screen

A 3MF can also reuse one object several times in different positions. The whole build can then be much wider than any one object: two 20 mm cubes placed apart can span 60 mm. Measure the object you care about, not just the overall build.

Example: an inch file converted to millimetres

Our inch example 3MF contains a cube 1 unit across, declared in inches and moved 2 units along X. Read correctly, it is a 25.4 mm cube sitting between 50.8 and 76.2 mm on X. Converted to STL, the numbers are written in millimetres, because STL cannot store a unit. Open that STL as millimetres. See how to convert 3MF to STL for the full check.

A common mistake is to correct the unit twice: once on the object and again on its placement. Apply the 25.4 conversion once.

Track down a wrong-size 3MF

  1. Keep the original file and note the unit it declares (or millimetres if none).
  2. Check the size of the object you care about, not only the whole build.
  3. Look for a saved scale on the object, a later resize, or a display-unit setting in the program you are using.
  4. If the size changed after exporting to STL, follow STL exported from 3MF is the wrong size.
  5. If the project itself needs a new size, scale the 3MF, save a new copy and check it again.

InspectMesh reads the common parts of 3MF, not every extension the specification allows. 3MF Core specification version 1.4.0, unit and transform sections reviewed 26 October 2026. A correct unit does not prove the model was designed at the size you need.
