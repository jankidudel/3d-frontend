To extract one placed part, open the 3MF in 3MF to STL Converter, choose its top-level placed item and generate a geometry-only STL. Preserve placement unless you deliberately choose translation. Inspect the reopened derivative before downloading, and retain the original project.

Which kind of object are you choosing?

Concept Meaning Selection boundary
Stored resource A reusable definition in the package May be used twice or never placed; resource count is not export count
Placed build item A top-level reference plus placement One selectable item, even when the same resource is referenced again
Nested component A child resource composed into a placed item Supported descendants export together with their top-level parent
Disconnected shell A connected triangle surface Connectivity does not recover original project identity

Worked example: select the second cube

  1. Download the two-placed-cubes control from the example collection. Its one resource has 12 triangles; two placements resolve 24.
  2. Load it in 3MF Viewer. Select build-2 using the row or the geometry. The selected spans are 20 × 20 × 20 mm; X runs from 40 to 60 mm.
  3. Use Isolate selected to inspect it and Show all to restore the other cube. Isolation affects viewing only.
  4. Open the same source in the converter and explicitly select build-2. Review the scope before generation.
  5. Leave Preserve resolved placement selected. Generate and verify: the reopened derivative must have 12 triangles and X=40..60 mm.
  6. Download the STL and report. Open it in the receiving application using millimetres and check a 20 mm edge and the retained location.

Nested composites and unplaced resources

A nested composite remains one selectable top-level item. Its technical details show component paths; selecting it includes every supported descendant. This first version does not offer individual nested-child or multiple-file selection. The unplaced-resource control stores an additional 100 mm cube without a build reference. It must not become an exported part merely because its definition exists.

Keep design intent with its source

Labels come from the uploaded file or neutral generated names. They do not authenticate the designer or intended machine. Extracting triangles cannot reconstruct editable CAD, material assignments or project settings. See the general conversion guide for format losses. If a required extension or invalid reference prevents resolution, use the original authoring application and request a supported geometry export rather than stripping package declarations.
