To extract one part from a 3MF, open the file in the 3MF to STL Converter, select the part you want, and export it as an STL. By default it keeps the part's position from the build plate; you can choose to move it to the origin instead. Check the exported STL before you use it, and keep the original 3MF.

What exactly are you selecting?

Term What it is What that means for export
Stored object A shape saved in the file It may be placed twice or not at all, so the number of stored objects is not the number of parts you can export
Placed part An object put on the build plate at a position Each placement is selectable, even if two use the same shape
Sub-part A shape nested inside a placed part Exported together with its parent part
Separate shell A connected piece of surface Being separate does not tell you which part it belonged to

Example: export the second of two cubes

  1. Download the two-placed-cubes file from the example collection. It stores one 12-triangle cube and places it twice (24 triangles in total).
  2. Open it in the 3MF viewer and select build-2 from the list or by clicking it. It is 20 x 20 x 20 mm and sits between 40 and 60 mm on X.
  3. Use Isolate selected to look at it alone, then Show all to bring the other cube back. This only changes the view.
  4. Open the same file in the converter and select build-2. Check what will be exported before generating.
  5. Leave Preserve resolved placement on and generate. The result should have 12 triangles and sit between 40 and 60 mm on X.
  6. Download the STL and report. Open it as millimetres in your slicer and check a 20 mm edge and its position.

Nested parts and unused shapes

A part made of nested sub-parts is selected as one item, and everything inside it is exported together. You cannot yet pick a single sub-part or export several separate files at once. A shape stored in the file but never placed (our example includes an unused 100 mm cube) is not exported just because it exists.

What the STL cannot carry

Part names come from the file or are generated, and do not prove who made the design. An STL holds only triangles: editable CAD, colours, materials and slicer settings are lost. See how to convert 3MF to STL for what changes. If the file uses a feature InspectMesh cannot read, export the part from the program that made it instead.

Keep the original 3MF together with the exported STL and its report.
