To check a 3MF for errors, work through four questions in order: does the file open, are all the objects there in the right place, are their meshes clean, and do the sliced layers look right? Stop at the first one that fails, because each needs a different fix. A clean mesh check does not cover every 3MF feature or slicer setting stored in the file.

First thing that fails What to find out Where to go
The file will not open Does it open in the program that made it? Go back to that program; mesh cleanup will not help.
It opens, but objects are missing or misplaced Which objects, positions, scales and units does it contain? Missing objects after import or the 3MF viewer.
Objects are there, but mesh errors are reported Which check ran, and where is the problem? Watertight check or manifold check.
An extra triangle needs removing Which triangle, and which objects use it? 3MF Repair.
Meshes are clean, but the slice looks wrong Which settings and layers are affected? Missing text detail, a missing top surface, or settings saved in the project.

Which InspectMesh check to use

3MF Print Preflight runs in your browser and combines several checks. The 3MF Quality Checker and the specialist checkers upload the file when you press check. The server checks each object separately; the browser check combines them, so results can differ. A check that failed or did not run is not the same as zero problems. Unlike STL preflight, 3MF preflight does not look for overlapping surfaces. See how InspectMesh checks files.

Also check size, wall thickness and volume

  • Size: compare the 3MF dimensions with one size you know. Placed copies can make the build larger than one object. A fit on paper does not include brims or supports, and scaling a part also changes its clearances.
  • Wall thickness: the wall thickness check samples the model, so "no thin areas" does not prove every area is thick enough. Check important features in the slicer preview too.
  • Volume: it cannot be calculated for open, duplicated, flipped or overlapping geometry, or sometimes for several parts together. Not available does not mean zero. See 3MF volume explained.

Keep a short record and check the final slice

Note the file version, the first step that failed, the tool you used and what you decided. The printable preflight checklist has space for this. Then reopen the saved file, confirm all objects are in place and inspect walls, hollows, materials and settings in your slicer. 3MF Repair removes extra triangles but does not fill holes or flip faces; for those, see how to repair a 3MF. Software checks do not prove strength or print success.
